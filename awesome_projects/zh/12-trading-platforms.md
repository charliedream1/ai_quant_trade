- **[vnpy](https://github.com/vnpy/vnpy)** — 开源 Python 交易平台开发框架，券商接口和策略开发工具丰富，被机构广泛使用。
  - 元数据： 语言： Python · 星标数： 45,645 · 许可证： MIT · 维护状态： 活跃 (最近推送 2026-09-13)
  - 文档／主页： http://www.vnpy.com
  - 使用点评：可作为券商与执行接入层；需核验券商支持范围和账户安全。

- **[freqtrade](https://github.com/freqtrade/freqtrade)** — 开源加密货币交易机器人，支持策略插件、回测、超参数优化与交易所接入。
  - 元数据： 语言： Python · 星标数： 55,248 · 许可证： GPL-3.0 · 维护状态： 活跃 (最近推送 2026-10-11)
  - 文档／主页： https://www.freqtrade.io/en/stable/
  - 使用点评：较成熟的加密货币策略自动化方案，需审查 GPL 许可与交易所风险控制。

- **[Jesse](https://github.com/jesse-ai/jesse)** — 提供研究、回测与实盘工作流的 Python 加密货币交易框架。
  - 元数据： 语言： Python · 星标数： 8,627 · 许可证： MIT · 维护状态： 活跃 (最近推送 2026-10-05)

## 券商与交易所接口

- **[CCXT](https://github.com/ccxt/ccxt)** — 支持 JavaScript、Python、PHP 的加密货币交易接口。
  - 元数据： 语言： Python · 星标数： 44,251 · 许可证： MIT · 维护状态： 活跃 (最近推送 2026-10-03)
  - 文档／主页： https://docs.ccxt.com
  - 使用点评：可统一接入加密货币交易所行情与订单路由；生产使用前需核验交易所支持情况与限流要求。

- **[Alpaca Python SDK](https://github.com/alpacahq/alpaca-py)** — 免费股票交易接口，支持模拟与实盘交易。
  - 元数据： 语言： Python · 星标数： 1,544 · 许可证： APACHE-2.0 · 维护状态： 活跃 (最近推送 2026-10-09)
  - 文档／主页： https://alpaca.markets/sdks/python/getting_started.html
  - 使用点评：可用于模拟或实盘券商接入；需确认地区可用性、资产覆盖与账户风控。

- **[StockSharp](https://github.com/StockSharp/StockSharp)** — 面向股票、外汇、比特币和期权的算法交易平台。
  - 元数据： 语言： C# · 星标数： 10,856 · 许可证： 其他／自定义 · 维护状态： 活跃 (最近推送 2026-10-05)
  - 文档／主页： https://stocksharp.com
  - 使用点评：可作为多市场交易平台候选；需审查许可证条款及 .NET/C# 集成成本。

- **[stock](https://github.com/bosspen1/stock)** — 基于 Java 的东方财富交易接口与自动交易工具。
  - 元数据： 语言： Java · 星标数： 0 · 许可证： APACHE-2.0 · 维护状态： 较久未更新 (最近推送 2023-03-21)
  - 文档／主页： -
  - 使用点评：面向东方财富自动化的专项参考；维护较久未更新、采用度较低，使用前应审查源码。

# 量化项目精选

[English](../en/README.md) | [中文](../zh/README.md) | [分类目录](README.md) | [语言入口](../README.md)

汇集、分类并点评优质量化项目、工具与学习资料，方便查找量化交易相关资源。

## 元数据标准

项目条目采用统一格式：

- **元数据**：开发语言、GitHub 星标数、许可证与维护状态。
- **文档／主页**：官方文档、主页；未找到独立页面时标记为 `-`。
- **使用点评**：说明项目适用场景，以及采用前应核验的事项。

维护状态依据 2026-10-11 核验的公开仓库活动：**活跃**指 2026 年有更新，**近期维护**指最近更新于 2024—2025 年，**较久未更新**指最近更新于 2022—2023 年，**不活跃**指 2021 年后无更新，**已归档**依据 GitHub 仓库归档标记。

# Factors

## Factor Analysis

- **[alphalens](https://github.com/quantopian/alphalens)** — Python library for predictive (alpha) stock factor performance analysis; works with Zipline & Pyfolio.
  - Language: Python · License: Apache-2.0 · Stars: 4.2k

## Technical Indicator Library

- **[TA-Lib](https://github.com/mrjbq7/ta-lib)** — Python wrapper for TA-Lib, providing 260+ technical indicators (C++ interface).
  - Language: C/Python · License: BSD
  - Install: `pip install TA-Lib` (Windows may need the wheel from [pythonlibs](https://www.lfd.uci.edu/~gohlke/pythonlibs/))
  - Chinese docs: [talib-document](https://github.com/HuaRongSAO/talib-document) (1.9k stars)

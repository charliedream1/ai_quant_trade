- **[RiceQuant (米筐)](https://www.ricequant.com/welcome/)** — Cloud quant platform.
- **[Uqer (优矿)](https://uqer.datayes.com/)** — DataYes quant lab.

## Open-Source Platforms

- **[JAQS](https://github.com/quantOS-org/JAQS)** — Early full-stack Python quant platform integrating data service, formula expression, strategy research, backtest and trading interface.
  - Language: Python · License: Apache-2.0 · Stars: 632
- **[rqalpha](https://github.com/ricequant/rqalpha)** — Extendable backtest engine from data acquisition to live trading; non-commercial use only.
  - Language: Python · License: Apache-2.0 · Stars: 6.6k · Docs: https://rqalpha.readthedocs.io/zh-cn/latest/
- **[QuantStudio](https://github.com/quantskills/QuantStudio)** — Quant x Work x Trade personal AI workbench (research, factors, strategies, spreadsheets, PPT); from PandaAI's QuantSkills community.
  - Language: Python · Website: https://www.quantskills.ai/ · Mirror (CN): https://gitee.com/quantskills/QuantStudio

# 统一策略标准端口设计

2026-10-30执行边界更新：创建/详情改为静态识别，取消展示时的隐式执行。运行时验证冻结字节、来源及源码摘要；内置与受控平台生成方案按已知来源识别，普通上传/CLI产物须显式SHA256复核后进入工作进程。源码变更后旧复核失效；AST与普通子进程均不作为恶意Python沙箱。以下早期dry-run描述由本段和28号设计修订。

## 1. 目标

统一策略标准端口用于把不同来源、不同书写风格的策略接入同一条执行链路。策略可以来自人工上传、egs 示例、trae cli、workbuddy cli、codex cli，也可以是后续其他生成器产物；平台通过端口识别、适配器包装、运行时 dry-run 预检，把它们转成回测、模拟盘和实盘都能消费的统一信号。

## 2. 支持形态

| 形态 | 典型入口 | 适用场景 |
|------|----------|----------|
| StrategyBase 标准类 | 继承平台基础策略类 | 平台内长期维护、自研策略 |
| 标准类端口 | 普通类中实现行情驱动方法 | 外部策略迁移、轻量策略脚本 |
| 函数端口 | 顶层函数直接返回信号 | 快速实验、CLI 生成的简短策略 |
| 对象端口 | 已实例化对象具备驱动方法 | 后续插件化运行和高级扩展 |

## 3. 生命周期

| 阶段 | 平台行为 | 策略侧职责 |
|------|----------|------------|
| 入库校验 | AST 安全检查、入口识别、参数定义提取 | 避免危险导入和危险调用，声明可识别入口 |
| 运行加载 | 通过加载器隔离导入策略文件 | 保持模块导入无外部副作用 |
| 适配包装 | 按类、函数或基础类包装为统一端口 | 返回可归一化的交易信号 |
| dry-run 预检 | 注入样例上下文和行情事件 | 验证入口可执行，提前暴露接口问题 |
| 引擎执行 | 回测、模拟盘、实盘使用同一信号结构 | 不感知执行环境差异 |

## 4. 标准数据

| 数据对象 | 说明 |
|----------|------|
| 执行上下文 | 承载参数、标的池、执行模式、账户快照和扩展元信息 |
| 行情事件 | 承载标的、时间、开高低收、成交量和原始字段 |
| 策略信号 | 承载标的、方向、数量、价格、信号类型、原因和扩展元信息 |

信号方向会做基础归一化，例如多头、买入、卖出等常见表达会转换为平台统一方向。策略返回单个信号、信号列表或空结果都可以被适配器处理。

## 5. 安全约束

上传和导入阶段继续使用AST作静态识别，不将黑名单当作隔离。实际运行先执行来源或复核检查；展示过程不执行dry-run。工作进程限制环境、文件、网络、时限和内存，是对已复核可信源码的纵深防护；未经复核的任意源码不能进入运行。对Windows长路径使用短UUID文件名，名称和版本保存在数据库。

## 6. 前端入口

策略参数由共享解析器统一处理，模型默认、源码声明、已保存默认、YAML 方案和本次覆盖逐层合并；缺省与空对象均继承。页面和 API 预览不执行策略或训练，回测运行保存完整解析证据。参数方案、验证和兼容规则见 `10_strategy_parameter_design.md`。

Gradio 策略构建页保留策略库、上传策略和 CLI 工作台，同时新增“预制策略”页签和 egs 示例策略预览与导入。策略详情页展示源码、基础信息、默认参数和接口检查结果，便于确认入口类型、能力列表、dry-run 信号数量和样例信号。

## 7. 示例位置

| 示例文件 | 覆盖形态 |
|----------|----------|
| egs/examples/strategy_examples/dual_ma_strategy.py | StrategyBase 标准类 |
| egs/examples/strategy_examples/standard_port_strategy.py | 标准类端口 |
| egs/examples/strategy_examples/function_signal_strategy.py | 函数端口 |
| egs/examples/strategy_examples/lightgbm_rank_strategy.py | LightGBM 截面模型类端口 |
| egs/examples/strategy_examples/xgboost_rank_strategy.py | XGBoost 截面模型类端口 |
| egs/examples/strategy_examples/mlp_ensemble_strategy.py | 小型神经网络集成类端口 |

这些示例均可从页面导入策略库，也可供单元测试和集成测试复用。

模型策略的训练与预测复用统一端口，但需要足够预热数据和日期对齐的多标的。模型只读取上一交易日及以前的特征与已到期标签，按配置间隔重训，下一交易日开盘执行；导入时的单事件 dry-run 不承担训练验收。回测结果附带模型诊断，记录拟合、样本外预测、日期与耗时。缺失依赖、样本不足、日期不齐或订单口径错误应明确失败。实现设计见 `09_model_strategy_design.md`。

## 2026-10-22 组合端口适配

组合版本发布时登记薄入口 `egs/examples/strategy_entrypoints/composition.py`，通过默认参数绑定方案及不可变版本。入口声明需要 composition 能力，旧 simple 单标的引擎明确拒绝，不用空 on_bar 返回值冒充已执行组合。新批次引擎沿用已有回测任务外键、净值/指标/成交格式，并返回阶段、组合目标和风险诊断。

组合执行校验入口源码、版本所属及定义/配置摘要；训练、Agent和目标撮合在批次运行中进行，导入预检不执行这些工作。旧策略显式请求数量仍受最大权重限制。普通策略的既有接口与Qlib边界不改写为组合能力。

# 因子研究与组合策略设计

2026-10-24，状态：按用户授权实施首批因子研究闭环。

## 范围与来源

保留 Gradio、图形策略工坊、版本编译器、组合账本与 Risk/Portfolio。新增因子集、横截面预处理、历史有效性筛选和因子合成节点，并允许既有模型选择独立特征集。多任务网络、遗传搜索、财务因子与实盘执行不在本批范围。

PandaQuantFlow 与 PandaFactor 仅作为功能和研究方法参考；不复制、翻写、移入其源码、配置或策略模板，不添加其依赖。所有实现由本项目的数据契约与验收要求独立推导。

## 数据契约与时点

因子面板以交易日期和证券为联合键，列为已登记因子。因子定义与集合放在 YAML，只允许登记的价量算子，不执行用户公式、外部 Python 或任意文件。每个值只依赖截至该日期的原始窗口；不足窗口、非法价格、缺成交量和陈旧行情保留缺失。

研究使用母池历史，不把今天筛选出的证券误当成历史股票池。当前候选仅决定本次评分输出。历史固定母池仍存在幸存者偏差，当前未复权数据仍不包含分红与公司行动。

预处理按每个日期单独计算，支持去极值后排名或标准分；零方差输出中性值，缺失不补零，不使用整段历史均值。行业、市值中性化须有历史可得数据，暂不提供伪代理。

## 节点和组合

因子集节点产生面板，预处理节点保持面板类型，研究筛选节点保持所选因子面板，合成节点才产生证券评分。编译器拒绝因子面板直接连接 Portfolio、投票或普通规则，拒绝不合类型的连线。

研究节点只使用预测标签已到期的样本，按日期对齐证券计算 IC、RankIC、非年化 ICIR、分组收益、覆盖率和因子相关性。复用现有监控的统计口径；去重按历史相关性和稳定顺序确定代表因子，保存入选与排除理由。分组收益是研究诊断，不是扣费组合收益。

合成支持等权和历史滚动 ICIR 权重。权重只来自已到期历史结果，对负有效性不反向追逐；支持向等权收缩和单因子上限。无合格因子时不回退至伪评分，样本不足与已验证不合格分别标记。因子权重、模型分支权重和 Portfolio 资金权重分别记录。

既有 LightGBM、XGBoost、MLP 可选择登记特征集；原默认特征不变。训练、验证继续按日期划分并清除标签重叠。训练证据增加特征名称与集合版本，原生模型摘要包含实际训练值。

## 缓存、页面与性能

原始因子按定义、证券、日期和实际输入窗口摘要缓存。追加新日期复用历史值；修订窗口数据会使相关值失效；缓存不保存未来标签。持久化仅在项目 data 目录或项目内隔离测试目录，使用 SQLite 数值记录，不加载 pickle。记录命中、计算、写入与耗时，文件操作遵循项目现有路径边界。

历史研究按日期一次提取数值数组并复用横截面，避免逐因子反复创建表格。提速必须同时核对原研究对象、评分、净值、订单、成交和成本，不以减少研究样本换取速度。

图形工坊增加因子研究分类、中文参数说明与模板；点击节点查看实际因子值、覆盖、历史研究、权重和排除理由。浏览、切换、编译与预览不触发数据、训练或缓存写入。API、CLI 与页面共用执行器和冻结版本。

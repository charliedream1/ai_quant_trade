# 策略参数方案与试验留档设计

2026-10-24 扩展：工坊因子参数使用独立 YAML 目录，发布时冻结因子定义和模型特征预处理口径；旧默认模型特征保持兼容。等权融合的整数/浮点表示统一规范，防止网页与 YAML 的等价数值误判为不同草稿。研究权重、分支权重和资金预算分别留档，详见16号设计。

2026-10-19，Codex。用户已确认，首期实现统一继承、YAML 方案选择、生效预览与运行留档。

## 参数来源与优先级

从低到高依次为模型默认 YAML、源码声明的默认值、数据库保存的策略默认值、所选 YAML 方案、本次运行覆盖。普通回测、策略一键回测、推荐衔接与 REST 回测均进入同一解析器；参数缺省、空对象和页面留空均表示继承，而不是清空默认值。

嵌套对象按字段递归合并，列表和标量整体替换；零值与布尔假值正常保留。源码中已声明的类型和上下界用于预检，快慢窗口关系由方案约束声明。平台元数据字段不允许作为策略参数传入。模型内部支持的参数仍由对应模型后端校验。

## YAML 方案组织

配置统一放在 egs/examples/strategy_params，每个 YAML 绑定一个源码入口名称，包含多个命名方案及其说明。现有十一种示例各提供基准和一个对照方案；基准方案继承保存的默认值，对照方案只覆盖差异字段，不宣称最优或保证降低换手。

模型方案同时声明关联的模型配置组，以便在无需训练的预览中展开完整模型默认值。自定义策略没有关联方案时，仍可使用源码与数据库默认值及单次覆盖；新增方案需确保入口名称唯一，并避免与其他策略重名。方案 ID 由文件名与方案名组成，只能选择属于当前策略的已登记方案，不能指定项目外路径。

## 页面与接口

策略一键回测和普通回测复用同一选择组件，包含方案选择、JSON 单次覆盖、只读生效预览与简短来源说明。切换策略或刷新方案会清空旧覆盖和预览，避免串用其他策略的设置。开始回测时重新解析，完成后展示已保存的实际参数。

参数方案列表与解析预览由策略 API 提供；创建回测请求新增可选方案 ID。预览只读配置与源码 AST，不导入模型、不训练、不请求行情。试验比较沿用已有回测参数对比入口。

## 运行证据与兼容性

复用回测任务原有 JSON 存储，不新增数据库列。数据库参数中保留执行条件及内部试验快照；API 将快照单独提供为 parameter_snapshot，原有 params 结构保留执行条件，避免页面参数摘要混入全部证据。

运行前深拷贝保存解析结果、各层输入、所选方案与文件摘要、策略名称/版本/源码摘要、执行条件、Python 与相关依赖版本、引擎及模型源码摘要。运行后补充实际数据源、日期区间、各标的数据量、净值点数和标准 OHLCV 摘要。股票池、验证比例与随机种子随实际配置一并保存；使用者仍需固定相同数据与运行环境才能复现结果。

这些记录不会因后续策略重命名、修改默认值或编辑方案而重新计算。旧任务缺少完整证据时明确标为历史原始记录，不推断当时未保存的模型默认值。OHLCV 摘要用于识别输入变化，不替代完整行情归档；外部 Qlib Workflow 的数据证据受其原生产物限制，缺失字段保留为空。

## 验收与后续

验证空参数继承、嵌套覆盖、零值、类型范围、跨策略方案拒绝、预览与实际一致、历史快照稳定以及旧任务兼容。对三种模型实际执行方案选择、训练、预测和回测，并核对运行日志与成交结果。浏览器检查选择、预览、运行及快照展示，检查延迟与控制台错误。

自动搜索在本期基础完成后实施。未来按时间顺序划分训练、验证和最终测试，搜索目标及成本口径独立配置，不用最终测试集挑选参数，不将本期手动方案比较称作自动调参。

## 2026-10-22 组合方案参数

组合方案按组件实例ID保存参数，模型默认、组件默认、方案variant及本次overrides解析后，在预览中给出全部生效值。风险和执行参数分开归组；零值是否禁用由各字段契约明确，不用真假判断丢弃合法零值。

已发布版本不接受临时覆盖；需要修改时从定义生成新版本。冻结定义、计算配置、实现摘要及训练环境用于复现；模型缓存键包含时点和已成熟训练样本，原生权重附校验摘要。页面编辑草稿自动清除旧版本ID，避免出现显示新参数却执行旧版本的漂移。尚未新增参数自动搜索。

2026-10-23图形参数表单沿用同一组件默认及编译器；图形修改先应用到YAML，运行入口比较两份生效定义，未应用则拒绝运行。子策略覆盖写入对应实例definition，不修改模板默认。布局、视口和选择不参与计算摘要或训练参数；详见15号设计。

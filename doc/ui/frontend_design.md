## 1. 设计原则与整体布局

### 1.1 设计原则

| 原则 | 说明 | 落地方式 |
|------|------|----------|
| 单进程可运行 | 当前项目优先保证本地个人部署简单可靠 | FastAPI 按业务域挂载 Gradio `/app/<module>/`；无需 Vite、Node.js 或独立 Web 构建 |
| 数据密集但清晰 | 量化交易界面需要高密度表格与图表 | 左侧模块/页面导航 + 当前内容 Tabs；先展示 KPI、信号卡片和图形摘要，再展示表格明细 |
| 金融终端风格 | 看盘、回测、交易类页面强调数字可读性 | 等宽数字、红涨绿跌、紧凑表格、状态条、KPI 和市场驾驶舱 |
| 闭环优先 | 策略研究入口应围绕因子、策略、模拟、归因和迭代组织 | AI 工作台作为研究到交易的主入口，投研看板只承担观察和分析 |
| 显式触发高成本动作 | LLM、远程同步、CLI 构建不隐式调用 | 使用按钮、开关或独立 Tab 触发，状态区显示结果 |
| 按域拆分 | 一级业务域不共享一个全站 Blocks 配置 | 十个独立 Gradio 应用拥有各自组件树、事件图和 `/config` |
| 延迟构建 | 启动和首屏不承担全站组件构建成本 | 每个模块由独立 ASGI 包装器在首次访问时构建、缓存并启动回调队列一次 |
| 不引入重前端 | 当前不需要 TypeScript/React/Vue/Vite | 页面、表格、表单、图表和流式工作台统一由 Gradio 承载 |

### 1.2 整体布局

```text
┌──────────────────────────────────────────────────────────────┐
│ `/app/` 持久工作台：顶部控制栏 + 左侧模块/页面导航              │
├──────────────────────────────────────────────────────────────┤
│ 内容区：独立模块同源 iframe，按首次选择延迟构建                 │
├──────────────────────────────────────────────────────────────┤
│ `/app/<module>/`：九模块独立调试与兼容直达入口                 │
├──────────────────────────────────────────────────────────────┤
│ `/legacy-app/`：迁移期完整单体页面，仅用于功能核对             │
├──────────────────────────────────────────────────────────────┤
│ `/help-docs/` MkDocs 文档站点                                 │
└──────────────────────────────────────────────────────────────┘
```

十个一级模块通过 `/app/` 左侧可收起导航在同一顶层页面切换，浏览器只下载和初始化访问过的业务域配置，并按最近使用顺序保留三个模块 iframe。模块和模块一级页面归入同一折叠导航，内容区只保留真正需要的明细 Tabs，可见导航最多两层。主题由 `ui_theme` 配置控制，顶部按钮支持浏览器本地亮暗覆盖。跨模块只传递 URL、数据库 ID 或稳定业务键，不引用另一个应用中的组件对象或 `gr.State`。十个 `/app/<module>/` 地址继续用于独立调试和兼容链接；`/legacy-app/` 仅用于迁移验收。

持久工作台顶部固定为紧凑科技风：左侧为始终可见的导航收起/展开按钮、LOGO、产品名和定位副标题，右侧保留 GitHub、Gitee、知识星球、市场切换、主题、刷新和独立窗口打开。导航使用本地彩色 SVG，一级和二级文字分别为 16px、14px；展开状态显示文字，收起状态显示图标，小窗口按按钮展开导航抽屉。嵌入模块隐藏自己的重复头部；通过 `/app/<module>/` 独立访问时仍显示完整公共头部和模块导航。刷新只重载当前活动模块，不影响工作台中其他缓存模块。

AI 工作台参考 `docs/archive/assets/workbench/main.png` 的功能导航与对话优先布局：左侧上半部提供新任务、自动化、MCP、Skill 和知识库，下半部为项目会话列表与折叠的项目/会话设置；点击历史项直接载入，进入独立 AI 模块时按需读取历史，构建页面不查询数据库。中央由紧凑工具栏、可伸展对话区和底部输入栏组成；输入保持约两行，右侧直接选择模型 API 或三种 CLI 并发送。文件预览默认关闭，使用右侧按需展开的文件面板；AI 工作栏可单独收起/展开，小窗口使用带关闭按钮的抽屉。

工作台以当前窗口剩余高度约束内容，取消整页滚动与固定最小高度；只有对话记录、会话列表、目录和长工具表单在自己的区域内滚动。隐藏面板不占布局空间，AI 主界面隐藏重复的悬浮助手，确保发送按钮不被覆盖。切换到其他 AI 页面或业务模块时恢复其正常滚动。自动化除新建、触发和历史外，支持按任务 ID 开启和关闭。

输入区支持附件拖放、文本提取和图片传递；发送时保存附件摘要并按后台能力处理。Codex CLI 使用只读 JSONL 事件流，Trae/WorkBuddy 未配置真实命令时明确返回未接入；策略构建页旧模拟器仍独立保留。

主题使用语义化的文字、表面、边框和阴影层级；暗色切换同时驱动 Gradio 原生控件和业务卡片，并同步给嵌入模块。关键布局与主题覆盖应以稳定应用标识为作用域，避免依赖框架生成的版本类名或让通用表格响应式规则覆盖 AI 满屏布局。壳布局、AI 样式及浏览器交互分别存放独立资源文件，公共主题负责装配。

**语言切换**：右上角「中 / EN」按钮在浏览器端通过 DOM 文本节点与常用属性遍历实现中英文切换（翻译字典来自 `src/frontend/i18n.py`，注入到前端 JS），选择保存在 localStorage 并在下次打开时恢复。翻译仅使用本地确定性词典，覆盖导航、按钮、表格标题、字段名和常见状态枚举，不调用模型，也不翻译股票代码、文件路径、代码块和长自由文本。

**市场切换**：数据层 `src/data/manager.py` 维护进程级市场状态（A股=CN、美股=US），可见入口只保留右上角「A股 / 美股」按钮；页面内 `market-switcher` 作为隐藏 Gradio 事件桥接器，承接右上角按钮触发后的后端切换、缓存清理和总览六组数据链式刷新。语言和市场强绑定：中文固定 A 股，英文固定美股；点击市场按钮也会同步切换语言，避免两市数据和界面语言混用。mock 模式提供美股模拟数据集（指数、板块、个股、新闻、研报）；real 模式下切美股自动降级为美股模拟数据并标注数据源。

### 1.4 首页信息层级与图表

首页以账户和风险为优先级，完整表格承担核对职责，默认折叠。1440×900 窗口首屏应同时包含控制区、异常、单组核心指标、净值趋势和资金配置图；下方按顺序提供仓位/集中度参考线、主要指数、板块样本热力图、持仓浮动盈亏、待办、执行状态和最多三条新闻。首页采用内容区自然滚动，不使用 AI 主界面的满屏禁滚动规则。

| 内容 | 数据口径与呈现 |
| --- | --- |
| 单组核心指标 | 当前可用行情估值、当天快照盈亏、相对初始资金盈亏、仓位暴露和最近快照回撤；取消重复卡片与无业务尺度的装饰进度条 |
| 净值趋势 | 只绘制已保存的有效快照，不补齐假历史，也不绘制无数据支持的基准线 |
| 资金配置与风险参考 | 现金与持仓市值构成环图；仓位、集中度采用真实比例和明确标注的首页观察参考线，不改变交易风控 |
| 板块样本 | 面积表示有效成交额、颜色表示涨跌幅；规模缺失时等面积，注明样本数量，不称全市场广度 |
| 持仓影响 | 展示浮动盈亏条形图，明确其不是今日收益贡献；无法估值的标的不按零处理 |
| 完整明细 | 保留十一类持仓、指数、自选、监控、风格、题材、路径、风险、交易、待办和运行数据；展开时补充低频明细查询 |

指标、配置图和持仓明细共用一次估值快照，缓存时间为实际估值时间。切换市场不改变持仓证券所属市场；跨市场且无币种换算的数据不作资产加总。实盘现有适配器仅提供配置资金，未收到 broker 资产回传时显示缺失状态，不能将其当作实时资产或真实持仓。

首页及自定义仪表盘数值表格保留原始数值、ID 和百分比格式。盈亏采用以零为中心的对称强度、正红负绿；成交额、市值等采用蓝色单向强度；风险/任务状态另附文本。专用单元格变量结合亮暗表面计算背景，覆盖斑马纹和悬浮行，但不覆盖其他业务模块的表格。普通文字对比度至少为 4.5:1。

页面、数据快照、图形、摘要和色阶按职责分文件；首页 CSS 只加入首页模块和兼容单体，不扩大 AI 模块配置。展示参数和颜色位于 `egs/config/ui/home_dashboard.yaml`。浏览器市场桥接器初始不选中，确保每次加载都将浏览器保存的市场选择同步给后台，避免缓存默认值阻止反向切换。

## 2. 前端文件结构

```text
src/frontend/
├── app.py          兼容完整界面的组合工厂与公共导出
├── modular.py      按模块构建独立 Blocks
├── mounting.py     延迟 ASGI 构建、队列启动与挂载
├── shell.py        持久工作台、模块容器与三实例客户端缓存
├── registry.py     模块元数据和稳定路径
├── navigation.py   跨应用 URL 导航
├── theme.py        CSS、浏览器 JS 和主题
├── common/         回调包装和公共组件
├── handlers/       页面可访问回调的业务域白名单
├── features/       dashboard/market/research/strategy/simulation/live/ai/knowledge/admin
├── service/        业务域回调、共享解析、展示转换和跨域契约
├── services.py     稳定导入与旧调用兼容门面
└── header.py       紧凑公共头部

src/help_docs/
├── builder.py      MkDocs 静态站点构建和 fallback 生成
├── mount.py        FastAPI `/help-docs/` 静态挂载
└── ui.py           Gradio 帮助页 iframe HTML
```

| 文件 | 职责 |
|------|------|
| `registry.py` / `mounting.py` | 定义模块路由；先挂十个子模块，再挂 `/app/` 父级工作台，并按首次访问独立构建、启动队列 |
| `shell.py` | 提供持久顶部栏、折叠模块/页面导航、同源 iframe 切换、浏览器历史恢复与最近三个实例缓存 |
| `features/*.py` | 每个业务域独立声明组件和事件，不引用其他页面组件 |
| `handlers/*.py` | 限制每个页面只能访问本业务域声明的回调集合 |
| `common/` / `theme.py` | 统一回调错误处理、表格/聊天组件、主题和浏览器行为 |
| `app.py` | 组合兼容完整界面，不再集中声明所有页面 |
| `service/*.py` | 按业务域调用同源领域服务，并完成表格、图表、Markdown 和 JSON 展示适配；公共解析与展示转换独立归档 |
| `services.py` | 聚合业务域实现，保留原有服务名、常量和帮助函数导入路径 |
| `api/app.py` | 创建 FastAPI 应用并挂载工作台壳、十个 Gradio 模块与帮助文档，负责压缩、静态缓存、异常处理、路由装配 |
| `help_docs/` | 帮助文档构建、挂载和 iframe 辅助，不承载业务页面回调 |

约定：

- 所有 Gradio 模块与 REST 路由共享领域服务，避免两套业务逻辑。
- 前端展示层不直接访问 SQLite；需要数据时通过服务层或领域类。
- 图表统一返回 Plotly Figure；表格统一返回 Pandas DataFrame。
- CSS/JS 只用于布局、视觉和轻量交互，不承载业务状态机。

## 3. 页面设计

### 3.1 模块化入口

根路径和 `/app` 跳转 `/app/`，`/app/` 直接提供持久工作台。工作台壳与每个一级模块拥有独立 `/config` 和事件图；访问一个模块不会构建其他模块。浏览器端只创建访问过的 iframe，并最多保留最近三个。`/legacy-app/` 只作为迁移期功能对照，全部浏览器验收完成后移除。

### 3.2 市场分析

#### 行情看盘

- 输入：板块类型、数量、自选分组与股票代码。
- 输出：指数表、板块表、板块强弱图、自选分组表、自选行情表。
- 交互：刷新行情、新建分组、批量加入自选、从分组删除标的。

#### 因子监控

- 输入：监控股票池文本框，默认读取 `egs/config/strategies/factor_monitor.yaml` 中的股票池。
- 输出：因子 KPI、RankIC 走势、分位收益柱状图、因子相关性热力图、有效性指标表、告警表和最新因子截面。
- 指标：RankIC、IC、ICIR、命中率、多空收益、覆盖率、换手率、分位单调性和样本数量。
- 加载：点击“刷新监控”时分两段加载，先返回状态/KPI、RankIC、分位收益、IC 衰减诊断图、分层收益时序和风格暴露诊断，再返回明细表、热力图和 Qlib 状态；避免切换到市场分析时自动触发重计算。
- 诊断：IC 衰减按配置的前瞻周期比较平均 RankIC；稳定性图比较平均 RankIC 与 RankIC 波动，点大小表示股票池平均换手率；分层收益时序展示 Q5-Q1 的滚动变化；风格暴露使用动量、反转、低波和量能趋势横截面代理；容量标签仅作为流动性与排序换手的代理提示。
- 边界：历史样本不足时显示样本不足和告警，不伪造因子有效性结论。

#### 新闻中心

- 输入：分类、关键词、来源。
- 输出：新闻列表、关键词强度图、新闻详情。
- 交互：普通查询读取本地快照；同步最新显式访问外部源。

#### 个股分析

- 输入：股票代码/名称/拼音/别名、K 线周期、K 线数量、自选分组。
- 输出：摘要、综合评分、财务表、K 线图、相关新闻、研报列表。
- 交互：点击分析后刷新全部分区；可将当前个股加入自选，也可同步当前代码到关系图谱并直接生成图谱。

#### 关系图谱

- 输入：中心股票代码/名称/拼音/别名、关系深度（1-5 整数滑块，默认 3）、关系类型 CheckboxGroup 多选。
- 输出：Plotly 网络图、图谱分析表、层级链路表、节点表、边表、图谱摘要（节点/边数、最大展开层、层级分布、主导关系、关系分布、节点分组、关键节点、链路分析、构建说明）和当前图谱 JSON 导出文件路径。
- 关系类型：行业 industry、概念 concept、指数成分 index、产业链 supply_chain、股东/机构 shareholder、新闻共现 news_cooccurrence、收益相关 correlation、关联任务 task、分析构建 analysis。
- 分组与路径：服务层按节点类型和关系边归并为关联行业、关联公司、关联板块、关联新闻、关联任务、产业链节点、股东机构和风险/风格因子等分组；节点表输出层级、父节点和中心到当前节点的路径；关联任务来自本地推荐、回测、Qlib 或定时任务中明确包含中心标的的记录。
- 深度：1 层为行业/概念/指数成分；2 层扩展同板块成分股、新闻共现；3 层扩展股东机构与关联标的板块；4 层扩展二跳标的与机构；5 层进一步扩散并补充新闻。
- real 模式下同层取数并发执行，单层 8 秒超时即降级，弱网下也能返回已完成层的子图；返回边统一按键去重。
- 服务层会在原始关系偏稀疏或最大层级低于用户请求深度时，使用本地主数据、中心行情、板块强弱、风险/风格节点、新闻关键词和验证场景构建可解释的多跳观察链路，并在摘要中说明补图来源；这属于研究解释层，不等同于确定金融关系。
- 性能：图谱查询按中心标的、深度和关系类型做日内缓存；Plotly 边线按关系类型合并 trace，降低边数较多时的序列化和浏览器渲染成本。
- 交互：勾选关系类型、调整深度后点「查询关系」重新生成；点「导出图谱JSON」将当前参数重新生成并导出摘要、分析、层级链路、节点和边；单选项和复选框使用自定义选中态（圆点/对勾清晰可见）。

#### 资源池

- 输入：资源池名称、描述、股票代码/名称/拼音/别名文本、权重、备注、证券主数据搜索词，以及 CSV / Excel 文件。文件列名支持代码、名称、权重、标签和备注的常见别名。
- 输出：资源池列表和资源池标的表，展示标的数量、总权重、来源和更新时间。
- 交互：可创建资源池、搜索证券主数据、手工批量加入标的、导入 CSV / Excel，推荐页可将当前推荐结果加入指定或默认资源池，也可把资源池内容载入推荐股票池。

#### 股票推荐

- 输入：推荐方案下拉、推荐路径 quick/deep 单选、推荐数量滑块（5-30）、股票池文本框（逗号分隔代码、名称、拼音或别名，留空取市场热门领涨股）；不使用 JSON 条件框。
- 输出：任务状态条 + 推荐结果表（中文表头：排名、代码、名称、综合评分、方案、推荐理由、动量、流动性、情绪、缠论、入选时间），入选时间统一转换为北京时间。
- 交互：可将当前推荐方案、路径、数量和股票池保存为推荐模板，并从模板库按 ID 回填参数；推荐结果表可批量加入指定或默认自选分组，也可加入指定或默认资源池；资源池内容可反向载入股票池；首只候选可同步到关系图谱，复核行业、概念、产业链、股东机构、新闻共现和收益相关；推荐候选验证区可生成当前方案的条件模板、候选因子对比图和候选对比表，也可对多组方案输出组间摘要、共识候选和覆盖热力图，并将前 5 只候选作为股票池创建回测任务，在推荐页内查看绩效、净值、交易和归因。
- 数据：real 模式下基于真实行情计算动量/流动性/情绪评分，非法代码自动忽略；缠论结构方案通过可选外部路径调用缠论结构分析器，失败时降级为本系统 K 线结构评分；deep 路径可调用 LLM，必须由用户显式触发。

#### 研报、模型报告和论文

- 研报：支持关键词/股票代码检索、详情查看、可点击链接和保存到知识库；检索结果附「研报分布」图（评级条形图 + 机构环形图）。
- 模型报告：支持按类型生成、刷新列表、按 ID 查看历史报告。
- 论文：支持关键词/来源/年份检索、查看详情、可点击链接、收藏或取消收藏，并可将元数据与摘要导入本地知识库；检索结果附「论文分布」图（年份条形图 + 来源环形图）。

### 3.3 策略构建

| 区域 | 组件 | 功能 |
|------|------|------|
| 生命周期 | Button + HTML + Dataframe | 读取策略、回测、模拟账户和实盘配置，展示阶段分布、生命周期明细和下一步建议 |
| 策略库 | Textbox + Button + Dataframe + Plot + Code | 搜索、刷新、查看详情、查看接口检查、启停、删除、同名版本比较、一键启动默认约束回测；列表附「策略分布」图（状态条形图 + 接口类型环形图） |
| 预制策略 | Dropdown + Button + Tabs(介绍/代码/超参) | 查看策略中文介绍、源码与可编辑 YAML 超参，校验接口后导入策略库 |
| 上传策略 | Textbox + Code + File + Dropdown + Dataframe | 保存源码或上传 `.py` 文件；手工追加参数字段、从源码提取 `params_schema` 默认值、预览并导入 egs 示例策略 |

| 产物导入 | Number + Textbox + Button | 将 CLI 产物导入策略库 |

预制策略区采用三个子选项卡：

- **策略介绍**：Markdown 渲染中文介绍，包含策略标签、适用场景、风险提示等元信息；介绍内容来自 `egs/examples/strategy_examples/strategy_intros.yaml`，由 `StrategyStore._load_example_intros()` 读取，解析失败时记录警告并降级为空介绍，不在源码中硬编码文案。
- **策略代码**：展示示例策略 Python 源码。
- **超参设置**：以 YAML 文本展示默认超参，可直接在界面编辑；导入时经 `yaml.safe_load` 校验，格式错误或非字典结构会被拒绝并给出中文错误提示。

切换预制策略下拉框时三个选项卡联动刷新；导入时仍执行标准端口检查，通过后写入策略库。

CLI Provider 当前需要支持 trae、workbuddy、codex，并通过策略层统一记录会话、日志和产物。
策略详情区展示策略源码、基础元信息、默认参数和标准端口检查结果，便于确认入口类型、能力列表和 dry-run 信号样例。

## 5. 回调与状态

Gradio 前端不使用前端路由和集中式 store。状态管理分三类：

| 状态类型 | 保存位置 | 示例 |
|----------|----------|------|
| 持久业务状态 | SQLite / 文件系统 / Parquet / DuckDB | SQLite 存系统元数据和索引；文件系统存文档原文和产物；Parquet 存持续增长的行情、因子与回测面板；DuckDB 做本地查询 |
| 回调瞬时状态 | Gradio 组件值 | 输入框、下拉框、表格、图表 |
| 浏览器轻量状态 | localStorage | AI 悬浮按钮位置、面板开合辅助状态 |
| 低频日内缓存 | 服务层内存缓存 | 总览分块、新闻普通查询、研报检索、论文普通检索、学习章节 |

回调设计约定：

- 默认按 Tab 懒加载，首屏总览拆成状态/今日必须看/KPI、账户焦点、市场要点、市场监控、账户持仓、策略任务多组回调，先返回轻量状态和四项高优先级决策信息，再逐块填充行情、账户和任务数据。
- 短只读查询设置 `queue=False`，避免进入长任务队列。
- 外部数据刷新、LLM、CLI、同步类动作必须显式按钮触发。
- 低时效页面按本地日期缓存；再次进入页面读取当天缓存，点击页内 `page-refresh-btn` 或顶部刷新按钮时强制重算，并在状态条或正文尾部显示最后刷新时间。
- 服务层返回结构应稳定，测试通过列名和关键内容断言。

## 6. 交互与体验规范

### 6.1 加载策略

| 场景 | 策略 |
|------|------|
| 首次进入 | 只加载总览，隐藏模块不触发外部数据请求 |
| 打开模块 Tab | 触发该模块默认数据加载 |
| 表格为空 | 返回包含提示行的 DataFrame 或 Markdown 状态 |
| 图表为空 | 使用统一空图，占位标题说明原因 |
| 长任务 | 展示状态 Markdown、日志 Textbox/Code、产物表 |

### 6.2 错误处理

回测与策略一键回测共用参数方案组件，提供 YAML 方案下拉、本次 JSON 覆盖、说明和只读预览。切换策略或刷新方案重置旧输入，运行完成回填已保存的实际参数；完整快照仍在回测证据区查看。参数选择不触发行情或模型训练。

策略构建增加 ETF 研究页，展示配置 ETF 池的基准、类别、费用、价格、历史点数、成交额和数据源状态；策略库的 ETF 预制策略与普通策略共用导入、参数和回测入口。AI 工作台专家团的复核工作流下拉支持普通回测复核和 ETF 策略投研复核。

- Gradio 回调用 `_safe` 包装，将异常转为页面可见的错误信息。
- 服务层输入校验使用 `require_text`、`require_id`、`parse_json` 等统一函数。
- 外部数据源失败时展示真实错误或降级说明，不伪造行情。
- LLM 密钥、API Key 等敏感值不进入日志和前端明文列表。

### 6.3 图表规范

- 金融数值使用等宽数字和清晰单位。
- A 股默认红涨绿跌。
- 图表标题必须说明数据含义，不使用装饰性图形。
- 关系图谱节点数量应限制，过密时使用 Top-K、阈值或最小生成树过滤。

### 6.4 移动端与小屏

- Row 内数据表和图表在窄屏自动换行。
- AI 悬浮窗宽度限制为视口宽度以内。
- 表格使用横向滚动，避免文本压缩到不可读。

## 2026-10-21 流式与布局验收补充

Gradio 安全回调包装必须保持生成器函数类型，逐次交付工作台六项输出或悬浮 CLI 三项输出；日志在迭代完成后记录耗时，迭代期间异常按现有错误提示处理。不能把生成器作为普通返回值交给组件。

工作台以数据库会话历史为准；悬浮窗历史把 Gradio 的文本内容块规范化为纯文本，并将规范化的前序对话传给 Codex。两处均按实际 CLI 事件更新进程、思考、动作和回复，不合成进度；同步兼容服务方法继续提供。

首页多个组件并行加载新闻时，由去重键的原子写入避免首次初始化冲突。浅色与暗色的导航标题、外链子元素分别继承工作台语义色；侧栏保持纵向滚动，约束子导航和说明浮层宽度，折叠时保留浏览器原生说明。持久工作台隐藏 Gradio 页脚，防止页脚占位导致满屏容器偏移。

## 2026-10-22 策略工坊页面

策略构建新增工坊二级导航，使用延迟动态组件；页面选择先切页签，再等待激活按钮挂载，避免空白及重复构建。2026-10-23起，内容顶部增加Gradio内的Svelte Flow图形组件，支持连线、参数、上下游与子图导航；原步骤、组合和风控表单按需展开。运行选项在左列，实际事件与报告在右列。未执行时隐藏空文件占位，完成后才显示下载入口。

保存版本后，手工改动草稿清空版本绑定；历史载入保留冻结版本。可选择API/Codex、模型、思考强度、日期、模式及已有决定ID；回测默认量化基线，回放没有原始决定则失败。报告使用隔离iframe展示，中文指标包含悬浮说明及可见计算解释，继续沿用蓝白与暗色主题。资源池通过同一服务执行方案筛选，不再增加多层页签。

图组件使用本地静态产物并按需加载；正常导航不调用行情/训练服务。布局与计算版本分离，图形修改必须应用后才能运行。受保护的Portfolio/Risk/执行节点不能断开；历史结果摘要不一致时提示旧定义。完整机制见15号设计和发布原理文档。

2026-10-24修复中，可编辑值与服务端patch分离：证据、布局回执、显式载入和应用确认按定义身份、编辑修订及请求顺序分别合并，旧轮询不替换新草稿。原步骤表应用后显式同步画布；载入同预置也重置未应用修改。预置布局按会话及方案隔离，全屏等待容器尺寸稳定后适配，证据刷新不重置视口。

## 2026-10-26 导航与报告体验

独立窗口保留当前视图、嵌套子页、任务/账户及冻结版本。定位程序抽成公共静态资源，嵌入与独立窗口共用；上下文按模块/视图隔离，连续导航取消旧挂载观察和延迟动作，重复事件只应用一次字段。仍按需构建并最多缓存三个模块，不增加常驻轮询。

报告库首次进入按需读取一次；来源、状态与关键词筛选后保留有效选择，显式刷新不会无条件清空。HTML缺失独立于原任务状态显示，禁止返回失效下载；缺失过程如实说明，异常记录不阻断其他报告。生成入口保留显式操作，不因列表刷新调用模型。完整约定见21号设计。

## 2026-10-27 文件阅读面板

AI项目文件、会话附件及知识库原件使用同一内嵌侧边阅读面板；主站仍为模块化Gradio。PDF.js与Markdown阅读脚本在对应文件打开时加载，不进入初始组件树。Office通过后台任务产生只读PDF，Markdown提供双栏编辑、保存、版本冲突和未保存关闭提示；其它格式只读，不引入Office编辑服务。

文件上传完成后才允许打开，支持连续更换；阅读启动同时处理Gradio内容节点复用与属性更新，避免第二次打开无响应。文档原件、提取文本和PDF缓存分别展示真实来源；静态上传HTML与现有交互Skill报告保持不同执行策略。亮暗主题、全屏和原件下载共用同一面板，阅读期间隐藏悬浮AI，关闭后恢复。详细约定见22号设计及文件阅读指南。

## 2026-10-28 两处对话框与Qoder后端

按25号设计统一主工作台/悬浮输入：附件图标在正文左侧，左下后端/访问权限，右下模型/思考强度/发送，模型旁提供按需刷新。提示使用placeholder，输入即消隐；Enter单次发送，Ctrl+Enter与Shift+Enter在选区处换行，输入法确认与重复按键不发送。选择后端先重置不兼容值，再更新模型；权限与通用推理菜单保持稳定，API仅只读，避免快速切换导致下拉索引失效。

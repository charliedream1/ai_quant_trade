# Runtime and workspace usability

## Scope

Support dedicated Conda environments in PyCharm, reduce provider authentication
noise, use the available viewport, complete visible English controls, consolidate
ETF tools within strategy management, and improve learning and form readability.
Keep dependency, network, model, task and stored-content contracts intact.

## Environment recognition

Strict startup accepts a dedicated virtual environment or a non-base Conda
environment with its own metadata. Explicit role-directory selections take
precedence. Configured names and base-installation marker directories identify
Conda root installations. Accepted environments must satisfy Python and application
version requirements and load packages from their own prefix.

Build-tool pins remain installation requirements rather than runtime gates.
A different pip version alone does not prevent a compatible application from
starting. Preflight never installs packages or modifies Conda environments.

## Provider output

BaoStock emits stdout for each authentication call. Use a call-local adapter to
route known successful messages to DEBUG and unexpected output to WARNING.
Preserve return values and exceptions. Never replace process-wide stdout or
modify installed SDK functions. Classification and levels belong to YAML.

## Layout and language

Use fluid outer containers, remove repeated iframe padding and retain responsive
gutters and consistent gaps. AI conversations fill their allocated region.
Readers use a bounded text measure, separate chapter directory, clear paragraph
spacing and scrollable tables. Do not scale the entire interface with zoom.

Translate display labels and explanations while retaining source component values.
Routing compares original labels after language changes. Preserve user messages,
code, model identifiers and source evidence. All quantitative chapters have real
English Markdown counterparts shared by the app and documentation site.

## ETF consolidation

Move ETF data tools into strategy management beside the catalog and presets.
Retain metadata, fees, liquidity and source snapshots. Remove the separate sidebar
destination, preserving old workspace and standalone URLs through an alias and
nested ETF tab. REST and CLI contracts do not change.

## Verification

Test Conda/base/explicit-prefix recognition, dependency and origin failures,
provider levels, ETF aliases, bilingual course coverage and translated routing.
Inspect wide, laptop and mobile browsers, chapter changes, AI sending, ETF refresh
and visible UI strings using explicitly mock market data. Run unit/integration,
lint, typing, privacy/dependency checks and both strict MkDocs builds. Stop owned
services, retain local memories and unrelated changes, and push reviewed commits.

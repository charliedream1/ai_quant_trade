# 依赖隔离与页面整合设计

2026-10-26，Codex。已按用户确认的方案实施：独立环境、锁文件、九项导航、共享组件及兼容跳转完成，正式测试与剩余边界见[实施验收](../../docs/audit/dependency_navigation_implementation_2026-10-26/README.md)。本设计不包含代码。

## 范围与边界

创建项目内不继承基础包的新环境，保持旧环境和业务数据；修复声明/实装不一致，统一主依赖、模型可选依赖、Qlib专用依赖和可复现锁文件。保持Gradio，不复制PandaQuant代码，不修改项目外包。若上游版本约束与安全修复冲突，记录兼容候选、无法消除的告警和调用边界，不强制绕过依赖解析。

导航整合优先复用服务与共享组件：研报论文与知识资料统一；RAG只保留一个会话界面；因子监控/挖掘统一；AI使用轻量配置快捷入口；回测/归因结果复用视图。图形工坊入口突出，ETF纳入导航。课程、帮助、资源池、行情和不同账户账本保留各自语义。

## 路由与状态

一级导航由十项收敛到九项，保留旧模块/视图映射及直接模块访问兼容。导航别名在进入目标页面前归一化，旧链接必须指向对应目标而不是回到默认页。共享入口通过明确的上下文传递证券、任务、账户及报告标识，保持冻结版本、会话与未提交表单。

保留模块延迟构建和浏览器缓存上限；统一导航不意味着一次渲染全部业务。只在激活对应内容时构建较大面板；快捷入口不重复请求数据或启动任务。

## 页面职责

| 页面 | 唯一职责与快捷关系 |
| --- | --- |
| 知识与资料 | RAG会话、资料管理、研报论文和报告浏览；旧研报模块进入同一目标 |
| 因子研究与监控 | 股票池、后端、观察日期、研究输出；市场保留摘要或跳转 |
| AI工作台 | 对话、Skill生成、专家流程；配置使用共享组件或带上下文跳转 |
| 策略管理 | 导入、参数和版本；一键回测提交后直达统一结果，提供图形组合入口 |
| 图形策略工坊 | 编排、发布、节点证据与组合运行；复用回测结果，保持本次执行快照 |
| 策略仿真 | 回测任务/结果、模拟账户、统一归因；来源与账户标识明确 |
| 系统管理 | 模型、MCP、Skill和定时任务的完整编辑与配置来源 |

报告生成器保留不同数据来源和运行协议，统一浏览及下载；CLI对话和策略产物生成保留不同任务类型，不能因合并入口自动执行或导入模型生成代码。

## 验收

新环境必须验证基础包隔离、实际版本、依赖解析、pip check、依赖审计和锁文件复现；模型与Qlib做真实小样本。页面验收覆盖旧链接映射、新导航、图形拖拽、ETF、资料检索/RAG、参数与费用、回测/归因及配置捷径，保存实际截图。

单元/API/CLI和整体回归通过后，比较模块配置体积、构建与切换延迟，检查后台任务数量，停止测试服务。同步使用截图、原理/API/spec、README、安装说明和周日志，保留实际错误及剩余告警。测试临时目录仍须用户确认后才能删除。

## 1. 目标与最小修改范围

在14号设计已交付的规则/模型/融合/Agent、Portfolio、Risk和批次回测之上，提供真正可操作的关系图。用户可以看清串并行、点选阶段、沿上下游跳转、展开子策略、编辑参数和连线，并从节点直接查找真实执行证据。

保留现有九模块Gradio工作台、导航、主题、版本、行情、模型、Agent后端、REST/CLI和执行引擎。优先替换工坊中的只读卡片与手填依赖交互；原步骤表和YAML保留为辅助视图。画布不是另一套计算引擎，不在本轮扩展因子公式语言、任意Python执行、深度网络或实盘委托。

## 3. 技术方案

采用“Gradio Blocks页面＋专用自定义图组件＋现有Python领域服务”。画布优先验证Svelte Flow，与Gradio组件的Svelte路径一致。组件只实现显示、交互和结构化事件，向现有服务提交合法的草稿变更及选择状态。

| 方案 | 结论 |
| --- | --- |
| Gradio标准表单和SVG导航 | 可用于第一步交互验证与兼容退路；完整拖拽、端口和子图仍需图组件 |
| Gradio自定义组件＋Svelte Flow | 首选验证；可复用节点/连线/视口等基础，参数与结果仍通过Gradio组织 |
| Gradio组件内使用LiteGraph Canvas | 备选；适合类似Panda的节点画布，但必须自行维护DOM表单、主题、键盘导航及数据绑定 |

库只按需装入策略工坊，不引入独立前端服务、第二套路由或跨域登录。构建产物随项目部署，运行时无需开发服务器或从CDN拉取脚本。开发依赖及构建锁文件保存在项目内，依赖版本以实际兼容测试为准。

当前requirements声明Gradio6.16.0，原模型隔离环境为6.3.0。阶段0在项目内新建`.venv-graph`验证6.16.0，并将模型运行所需LightGBM安装到该隔离目录；没有改动conda或原模型环境。自定义组件通过Gradio HTML的值、watch和事件接口通信，不依赖查找隐藏Textbox、模拟点击或全局DOM轮询桥接。旧版保留表单/YAML并提示兼容范围。

## 4. 页面组织与节点导航

维持现有可折叠业务侧栏。工坊正文分为左侧可收起的组件/方案目录、中间主画布、右侧属性/证据面板，下方按需展开运行时间线；不增加多层业务页签。

| 区域 | 拟提供内容 |
| --- | --- |
| 顶部工具栏 | 方案/草稿状态、保存/发布、预览、运行/取消、撤销/重做、适应全图、自动布局、搜索 |
| 组件目录 | 数据上下文、规则/形态、模型、融合、Agent、Portfolio、Risk和子策略；搜索、用途和能力说明 |
| 画布 | 带箭头和端口含义的关系、分支、融合、分组、预算标签和运行摘要 |
| 属性面板 | 常用参数表单、完整生效值、上游/下游、数据需求、说明、错误及当前运行结果 |
| 运行时间线 | 按节点、日期和阶段过滤的真实事件；可定位失败节点、打开HTML/中间结果 |

交互要求：单击选中并显示属性；双击子策略进入内部图；点击上游/下游列表或连线端点聚焦对应节点并高亮依赖；搜索标识/名称后定位；支持全图、选区聚焦、缩略图和平移缩放。键盘可选中节点、跳上游/下游、返回父图，说明文字不依赖颜色。

面包屑为“总组合→子策略→当前阶段”，同页切换并保存各层视口及选择。全局节点身份使用子策略路径加实例ID，与文件系统路径无关；不得以用户输入路径读取任意文件。可保存当前模块/view/节点/运行查询状态，浏览器前进后退恢复位置，不重新运行策略。

## 5. 图形含义与现有方案映射

必须明确区分三种关系：筛选/评分数据流、子策略资金预算、运行证据定位。实线箭头连接候选/评分/决定等输出；子策略预算边标明资金比例；模型训练的母池和时间上下文以只读关联展示，不伪装成当前运行器不支持的多输入计算。

节点端口由组件目录定义，候选集、连续评分、研究决定、目标权重、风控后目标及结果引用采用明确语义。画布基础库只判断是否可连，最终合法性由后端决定。

| 图形操作 | 对现有业务定义的映射 |
| --- | --- |
| 添加规则/模型/融合/Agent | 对应节点实例、组件类型、参数和inputs |
| 增删计算连线 | 修改目标节点inputs，保持有序融合权重与来源一起更新；编译检查依赖及类型 |
| 选择最终阶段 | 修改output；展示其后组合/风险/执行链路 |
| 编辑Portfolio/Risk | 通过画布中的专用配置节点编辑现有portfolio/risk段，而非插入未支持的普通规则节点 |
| 编辑多策略预算 | 修改sleeves及预算分配方式，保留总组合与各子策略范围/局部风控 |
| 移动/缩放/折叠 | 只更新布局和视口，不修改计算版本或模型缓存键 |
| 打开执行结果 | 根据运行ID、冻结版本、子策略路径、节点及as_of读取已保存证据 |

Portfolio、Risk和执行在首期为受保护的流程配置节点，图中如实显示必经顺序；只有属性和允许的方案可编辑。删除或断开视觉节点不得关闭后端硬限制。独立风控监控的持续性也不由当前研究画布是否打开决定。

原模板中的多个模型通过融合节点组合；多子策略通过预算节点汇总并净额。二者分别标为“评分权重”和“资金预算”，不能用相同百分比标签混淆含义。风险削减后保留现金，不因图形分支变化自动重新归一。

## 6. 参数、布局与运行状态分离

计算定义继续沿用现有方案及不可变版本；适配器将画布编辑转换为同一份规范定义。界面表单、YAML和画布共享草稿状态，不能彼此覆盖成三套方案。导入时明确格式版本和支持节点，未知组件、外部代码和不合法字段拒绝执行。

布局文档独立保存坐标、分组、视口、折叠、选择及可选显示名称；绑定方案/草稿身份和结构摘要，可随运行保存只读布局快照。坐标或显示名称变化不改变训练和执行摘要，节点改名、依赖、参数、预算和股票池变化需要重新校验并发布新计算版本。

运行状态是第三份只读数据，标识运行ID、冻结定义摘要、as_of、节点路径、实际阶段及事件序号。历史结果始终绑定当时定义；当前草稿变更后显示“结果来自旧版本”，不把旧图染成新方案执行成功。客户端和后端均校验草稿修订号，防止较早的异步校验/选择结果覆盖较新的编辑。

## 7. 节点参数表单与类型校验

借鉴Panda的输入模型与元数据思想，扩展现有组件目录的参数类型、默认值、范围、选项、单位、帮助和端口基数。默认展示中文常用字段，例如均线窗口、RSI阈值、模型训练窗口、融合权重、最大仓位和止损；复杂字段保留高级JSON/YAML。

字段值来源必须区分“人工参数”和“上游绑定”，相同字段不能同时默默采用两种来源。模型母池保留全部合法历史，不因前级当日过滤缩小训练集。评分融合检查预测期、目标语义、参考母池及可用分支，未知不作零分、空结果不放松筛选。

连线编辑支持实时提示自环/循环、重复边、未知节点、缺少必需输入、非法多输入、类型不匹配及无效最终输出。后端在保存、发布和运行前重复校验；错误必须返回可定位的节点/端口路径和中文原因。拖动节点不会自动训练、请求行情、调用Agent或触发模拟成交。

## 8. 运行观察与局部检查

复用既有阶段、训练/缓存、组合、风险、Agent和报告事件，并补足子策略命名空间及可恢复的事件游标。前端仅增量更新节点状态；切页或断连后可读取终态和缺失事件，不重复提交任务。

选中节点后查看通过/淘汰/未知数量、耗时、输入来源、输出摘要和对应证券原因；模型展示真实训练/缓存及到期验证信息，Agent展示实际后端、公开过程、引用和失败，Portfolio/Risk展示目标/实际持仓差异、约束与现金。

回测按交易日循环执行，同一节点会多次训练或预测。图中默认展示所选日期/阶段，并单独给出全程汇总，不把一次绿色状态当整个回测永久完成。进度以已完成阶段/日期和真实状态显示，不按定时器制造百分比。

首期的“查看当前步骤”读取已有中间结果。对失败节点重试或“从此节点继续”需先证明所有上游结果与相同冻结版本、数据时点、模型和参数一致；涉及训练、Agent或持仓执行不自动局部重跑。本轮范围不包含任意分支增量执行器。

## 9. 性能与生命周期

保留工坊延迟加载。平移、缩放、选中、高亮、搜索和子图导航在浏览器完成，参数/连线变更只做防抖校验，保存/预览/运行才提交必要请求；结果表和大型行情/模型文件按需读取，不塞入每帧组件值。

组件采用稳定身份，避免每次选择重建整个Gradio子树。注册和销毁监听器/定时器、隐藏模块及重开画布都要验证；ResizeObserver和主题切换更新可视尺寸/颜色，不重新计算策略。布局保存限频，纯选择不会生成模型训练、计算版本或审计噪声。

以现有配置的最多40节点、3层子策略作为首批基准，测试冷加载、暖导航、编辑、事件更新、内存和产物大小。前端交互目标为同机暖导航P95不超过150ms、连续操作无明显卡顿，属于待测目标；若超限必须明确瓶颈，不能以归档回测耗时替代界面指标。共享引擎的净值、成交、费用和风险结果在相同定义/数据下必须一致。

## 12. 当前范围与决策

已采用Gradio组件＋Svelte Flow 1.7.0，Svelte 5.57.2和Vite 8.3.5的本地构建，锁文件及许可证随源码保留。图投影和布局存储实际位于前端服务的独立小模块，没有新增第二份领域定义或改写历史版本。风控和执行节点保持受保护；已有七套策略共用原执行器。

实际交付包括组件拖入、端口连线、复制/移除、常用参数和完整JSON、撤销重做、布局持久化、导入导出、父子图和浏览器层级历史、真实事件与节点摘要。运行入口拦截未应用的图形计算变更，避免画布与YAML漂移。只读证据使用有界索引和近期预览，并在终态停止轮询。

首期没有增加任意日期全量图查询、独立阶段续跑、布局随每个运行冻结副本或任意分支增量执行器；历史运行继续绑定冻结定义及原报告，节点证据可定位到实例路径。完整事件、交易日期和证券明细从原附件读取。C的长期数据与高级研究扩展继续独立推进，真实Linux桌面尚未实机验收。

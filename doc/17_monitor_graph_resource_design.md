保持现有 Gradio 前端、Plotly 图表与统一领域服务。解决 Qlib 状态含义不清、因子监控范围小、图表缺少完整解释、图谱空白及关系可信度不足、资源池缺少模板与统一上传校验的问题。

## 一、Qlib 与通用因子监控

### 本地只读环境核查

本轮分别使用项目 `.venv-graph` 和 `.venv-models` 的 Python 检查，均未找到 qlib 模块，当前 PATH 未找到 qrun；示例引用的 `egs/qlib_workflows/alpha158_lgb.yaml` 与 `D:/qlib/qlib_data/cn_data` 也不存在。检查没有导入 Qlib、创建数据库、安装包或调用真实行情。这里不推断其他 conda 环境或用户另行启动服务的环境状态。

因此 missing 有明确来源，但当前页面将可选依赖诊断与内置监控并排，容易让人误以为所有因子计算都失败。另一个问题是，即使模块可发现，现有 available 状态也不足以证明真实运行就绪。

### 建议的能力划分

| 模式 | 使用能力 | 就绪条件 |
| --- | --- | --- |
| 内置因子研究 | 统一日期面板、因子目录、已到期标签与监控指标 | 合法股票池及相应行情，不依赖 Qlib |
| Qlib 因子与信号分析 | Qlib 数据表达式、信号分析和实验产物 | 可执行的 Qlib 环境；按调用方式准备 provider 或输入面板、分析配置 |
| Qlib 模型与组合 Workflow | 训练、预测、信号与组合分析记录 | 额外准备真实 Workflow、模型依赖、数据与执行入口；走 qrun 时检查其真实路径 |

直接调用 Qlib 因子/信号分析不要求每次都训练模型，也不能一律把 qrun 和完整模型 Workflow 作为其前提。建议提供显式后端选择，不静默回退；结果显示实际后端、数据范围、股票池版本、观察日、标签周期、软件及参数版本。

[Qlib 官方 Recorder 文档](https://qlib.readthedocs.io/en/stable/component/recorder.html)提供信号分析记录，包含 IC、ICIR、RankIC 与 RankICIR；[在线模块](https://qlib.readthedocs.io/en/stable/component/online.html)提供预测与标签更新等机制。本项目需要额外实现增量调度、可用标签筛选、持久化、告警和 Gradio 展示；安装包不会自动形成监控产品。

### 实施边界

- 复用现有日期对齐面板和统一因子目录，修正旧页的行号拼接、覆盖率分母与静默截断；支持市场基准、策略范围和当前持仓三类股票池。
- 页面区分“内置监控可用”“Qlib 分析后端未配置”“数据未就绪”“Workflow 未就绪”“上次真实任务成功或失败”，环境明细折叠显示。
- Qlib 优先使用项目内隔离运行环境，通过明确解释器调用工作进程；诊断实际工作进程，不能仅用 Web 进程的 find_spec 否定独立后端。依赖版本必须以实测结果确定，不修改已有 conda 包。
- 数据包含交易日历、证券市场身份、历史成分及有效日期、复权政策；缺少历史成分时标明“当前成分回看”。数据更新与预测更新分开，未到期标签不参与评估。
- 同一输入面板对照两个后端的 IC/RankIC，明确 ICIR 的标准差、年化与缺失值口径；不能直接比较名称相同而定义不同的数值。
- 页面读取后台任务和缓存结果，展示真实阶段与错误；不因切页重训，不用虚假进度填充空闲时间。

## 二、全站图表与概念解释

当前已有说明应保留和统一，补齐缺口。采用同一份 YAML 说明目录，按稳定图表标识管理标题、短说明、轴含义、单位、读图方向、计算口径、数据来源、局限与使用文档链接；避免在各页 JavaScript、图标题和帮助文档中分别维护相互矛盾的描述。

建议三种入口同时存在：标题旁可悬停及键盘聚焦的说明按钮、图下常驻的一句读图提示、可点击展开的完整说明。点位悬停补当前数值、时间、单位和样本；不能让所有解释只能靠鼠标悬停才能找到。复杂图提供简短概述、完整说明与底层数据，是 [W3C 图表说明建议](https://www.w3.org/WAI/tutorials/images/complex/)的可借鉴方式。

| 图表 | 必须说明 |
| --- | --- |
| 风险雷达 | 每条轴的定义、分母、百分比、越外含义；快照回撤不等于完整历史最大回撤，参考线不触发交易 |
| 情绪雷达 | 当前为指数动量、板块上涨比例和板块一致性等代理；0—100 为映射分数，不是涨跌概率 |
| IC 与分组收益 | 因子定义、池与样本数、观察日/标签到期日、正负含义、组内数量及是否计成本 |
| 净值、回撤与滚动指标 | 基准、年化周期、费用、窗口长度、缺失处理与回测区间 |
| 相关性与风格热力图 | 行列对象、色阶与取值范围、收益/价格口径、行业或价量代理边界 |
| 主题与新闻图 | 样本来源、观察窗口、提词规则、重复处理与热度含义 |
| 关系图谱 | 关系来源、方向、正负、权重口径、证据日期、事实/推断分类 |

缺失值不能默认伪装成 0；应显示无数据及样本限制。雷达各轴不是同一物理量，面积不能直接理解为统一风险或情绪总分。对于需精确比较的值，提供相邻条形/数值视图，避免只能从雷达面积猜大小。

说明随页面懒加载，不调用模型或额外行情接口。后续使用文档配真实截图；这一轮设计不新增模拟页面截图。

## 三、图谱布局与关系可信度

### 布局

本轮按当前圆环公式作纯内存推演：三层各一个节点时，横坐标约为 0.6702、0.9993、1.2393，全部在中心右侧；固定范围仍包含完整负半轴，足以解释稀疏链路的左侧空白。此推演不是对用户当前浏览器的端到端复现，也不排除隐藏 Tab 初始尺寸和父容器宽度问题。

最小方案是按节点实际包围盒与标签留边确定范围；稀疏图使用居中的紧凑层次布局，多节点图均匀分布。容器可见和尺寸稳定后再适配，支持重新居中、适应全部、缩放与平移；折叠左导航、改变窗口和主题、切回页面后保留合理视口。[Plotly 轴约束文档](https://plotly.com/python/axes/)说明等比例轴会影响 range/domain，需结合容器验证，不能只改固定宽度。

首期继续使用 Gradio/Plotly。节点或关系列表选择后定位证据；如增加图上点击，以小型且可测试的事件桥实现，不假定 gr.Plot 原生具有所有交互回调。控制标签密度、仅显示选中节点邻居或展开下一跳，避免为铺满画布放入无依据节点。

### 当前新闻方法与缺陷

真实源路径先按股票代码调用东方财富新闻搜索；新闻返回结果直接连接中心股票，关键词列表还主动加入查询代码，因此不能再拿该关键词作为“原文命中股票”的独立证据。同业扩散主要检查公司名称是否出现在标题和摘要中。新浪回退路径先检查源数据中的证券代码标记，证据类型应与文本提及分开记录。

服务层另有无个股匹配的市场新闻补图和为达到深度而补链路的机制。分析构建虽有类别及整体说明，仍会造成已知事实、市场背景与推断线索混看。默认应停止把这些内容作为事实关系输出；深度表示最多探索几跳，实际只有一层时如实显示一层。

图谱新闻名称目前可能显示代码或过短关键词；边只保留关系类型、说明和权重，缺少稳定的文章身份与完整证据。需要保留来源字段经过服务规范化、API、导出和界面全过程。

### 新关联规则与展示

先用证券主数据的代码、正式名称、已验证别名和来源标记召回，再验证正文或摘要中的对应实体及上下文；处理重名、泛称、跨市场代码和历史名称。区分公司直接提及、同文共现、行业政策影响、仅主题相似四类，禁止把主题相似自动当成个股已确认事实。

如果后续加入语义模型，只用于候选检索与重排；语义分数不等于事实关系。[Sentence Transformers 官方检索与重排说明](https://sbert.net/examples/sentence_transformer/applications/retrieve_rerank/README.html)支持分阶段检索思路；[spaCy 官方概述](https://spacy.io/usage/spacy-101)区分实体识别和实体消歧。首期优先规则、证券主数据与证据提取，不默认引入模型下载或每条新闻调用 Agent。

每条关联至少展示：新闻标题、来源、发布时间、原文链接、命中的代码/名称/别名或源证券标记、证据片段及所在字段、关联类型、提取方法及版本、观察时间。只抓到标题和摘要时明确证据范围，不声称已分析全文；未找到证据的新闻不画事实边，可单独列为待核查线索。

权重区分结构关系权重、检索相关分、统计相关系数与模型置信值；没有校准的分值不写“可信概率”。原文展示做安全转义，不直接渲染来源 HTML。

相关性边同步改为真实交易日期交集上的收益序列相关，记录区间、有效样本、复权与停牌处理；保留系数正负。边宽可表示绝对强度，但颜色和说明必须区分同向与反向，样本不足时不生成统计关系。

mock 数据继续服务演示和隔离测试，但整图及导出必须带来源标记；真实数据模式缺失时，不混入模拟关系。推断线索单独开关，默认关闭，不计入已确认关系数量。

## 四、资源池模板与上传校验

### 模板

页面增加“下载 CSV 模板”“下载 Excel 模板”和字段说明，模板源文件放在 `egs/resource_pool_templates/`，使用文档放在 `docs/usage/` 并配下载、预览和导入结果截图。前端/API/CLI 读取同一份字段规范和静态模板，不在多个回调内拼不同示例。

建议标准字段包括：市场、证券代码、名称、候选评分权重、标签、备注。保留已知中英文列别名，证券唯一身份使用市场与标准代码。明确当前资源池 weight 的消费含义，不因字段名就认定为总和必须为 1 的目标仓位；如增加目标仓位，应使用独立语义并在策略约束处验证。

既有数据的身份字段与唯一约束需先核查并作可恢复迁移，不直接覆盖旧池。混合市场文件按当前策略与数据能力分池或明确阻断，不能因新增市场列就宣称已支持跨市场组合回测。

CSV 使用带 BOM 的 UTF-8；Excel 证券代码列设为文本。解析全程保留前导零，只有确定为 A 股身份后才可按规则补全数字代码，不能对所有市场统一补六位。缺少合法代码列直接报错，不再猜第一列。旧文件缺少市场时允许采用当前市场，但须在预览中明确展示推断结果。

### 统一流程

采用上传、解析与逐行校验、预览差异、显式提交的流程。Gradio、API 和 CLI 共用同一领域解析/校验服务；预览不创建默认池、不写标的、不批量触发行情请求。提交绑定文件内容摘要、字段规范版本、目标池及冲突模式，并检测预览后目标池是否发生变更。

| 层级 | 校验与反馈 |
| --- | --- |
| 文件与格式 | 允许的 CSV/XLSX，实际内容结构、编码、空文件、损坏/加密工作簿、大小、解压后体积及行列数量限制；限制由 YAML 管理 |
| 字段 | 必填列、重复表头、未知列提示、字段长度、空代码、非法字符；不执行公式，不跟随外部链接 |
| 证券身份 | 市场归属、标准代码、别名歧义、名称/代码冲突、主数据未知项；外部查询失败单独报告，不能当成已核实 |
| 数值 | 权重必须为有限数；负值及上限按字段与策略约定校验；非法输入不默认为 1，不接受 NaN/Infinity |
| 重复冲突 | 文件内及目标池已有项分别提示，显示新增/更新/跳过；合并、覆盖等选择在预览中明确，不静默最后一行覆盖 |
| 提交 | 校验错误默认整批阻断，数据库事务保证原子性；需要部分导入时显式选择并保留逐行结果，失败不留下半批数据 |

支持下载包含行号、字段、原始值、问题与修正建议的错误报告。CSV 错误报告对公式起始字符作安全处理；不以安全清洗为由静默改变证券身份。旧 XLS 格式单独评估解析依赖并明确兼容政策，不能网页宣称支持而 API 拒绝且无提示。

当前 API 会一次性读取上传内容，需在读取与解析阶段控制大小，结合格式检查，而非只相信扩展名或 MIME。这与 [OWASP 上传建议](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)一致；实施范围限于当前导入路径，不引入无关审批流程。

## 实施说明

- 内置与Qlib共用日期面板、因子目录及已到期标签，支持滚动窗口、多池对照和用户历史成员版本。当前指数/全市场名单仍是当前成分回看；历史行业与市值未完整提供，不冒充中性化或显著性检验。
- 页面真实运行期间才轮询，图表说明静态资源按需加载；Qlib多个前瞻周期合并到一次工作进程调用。正式证据保留优化前后数值和耗时。
- 图谱停用并移除无证据补链，修正价格水平误标收益相关；自适应范围之外还修复了图例右锚点造成的自动左边距。新闻证据贯穿源、服务、API与页面；真实来源没有相关文章时为空。
- CSV/XLSX模板及统一校验已接入网页/API/CLI，采用预览摘要绑定、冲突提示和事务。现有池仍按单市场使用，混合市场文件阻断，未改原唯一约束或宣称跨市场组合执行。
- 当前不提供推断线索开关、语义模型关系抽取或完整PIT数据供应；这些没有混入事实图谱。少量未知主数据证券只通过代码格式校验并显示提示。

# 数据来源、时间与缓存

页面、REST 和 CLI 共用领域服务，但界面就绪不等于外部数据源可用。每次研究应同时记录市场、模式、来源、更新时间和实际覆盖区间。

| 阶段 | 处理与边界 |
| --- | --- |
| 请求上下文 | 按 CN/US 隔离市场；查询和回测使用请求对应的市场 |
| 数据管理 | 真实源可能限流、失败或仅提供最近窗口，备用源不保证补齐完整历史 |
| 缓存 | 行情短时缓存与页面日内缓存降低重复访问；强制刷新可能重新请求外部源 |
| 历史过滤 | 真实 K 线必须处于请求区间，无交集返回错误；不会退回区间外行情 |
| mock | 合成 K 线映射到请求区间工作日，保留 mock-local 来源；不是交易所完整日历 |
| 结果留档 | 保存实际日期、来源及行情摘要，用于识别后续数据变化 |

新闻按去重键原子写入，避免并发初始化重复插入。展示上限不保证实际条数；跨市场和时段不能只比较数量。情绪、主题和风险中的代理值必须结合原始新闻与行情理解。

冷加载包括外部请求、数据整理及组件渲染；暖缓存只反映重复访问。性能比较应固定市场、账户、数据模式与刷新方式，不能用 API 配置响应时间代替浏览器可用时间。

# 通用因子监控原理

监控复用策略工坊的因子定义、日期面板和已到期标签研究，不再维护一套固定四表达式的独立算法。统一目录包含动量、反转、低波、量能、均线偏离、收盘位置、平均成交额和日内反转。

## 股票池是结论的一部分

横截面 IC 在某一天比较指定股票池中的因子与后续收益，因而依赖证券范围。市场基准池用于观察市场表现，资源池用于策略适用性，持仓池主要用于暴露观察；少数持仓不能证明全市场有效。

每次结果记录池的市场、成员、版本、观察日期、来源与历史政策。当前指数名单标注“当前成分回看”；用户历史清单按有效日期逐日筛选，成员变更不能只改变结果标题。请求但加载失败的证券仍进入对应观察日的覆盖率分母。

系统没有自动提供历史指数成分、历史行业和市值数据，因此没有把这些入口称为历史无偏或行业中性研究。

## 日期、因子与标签

行情先按证券真实日期去重、过滤无效价格，并截至观察日；因子只使用该证券当前及此前窗口。面板索引为日期与证券，不再按不同股票各自的行号拼接。

前瞻周期使用输入行情日期并集。标签只有在统一日历的终点日期已到期、起终点价格均存在时才计算，期间收益为终点收盘价除以起点收盘价再减一。停牌或缺失不能用后一个有价日期偷偷缩短/延长目标周期。日历来自输入行情，不等于独立交易所完整日历。

最新因子截面与最近一期可评估 IC 是不同时间：前者可到最新行情，后者需要等待未来标签到期。界面和结果分别保留观察日、标签终点与快照日。

## 指标口径

IC 是同日期有效因子与标签的 Pearson 相关；RankIC 是 Spearman 秩相关。常量截面、有效证券不足或样本缺失时不输出伪造的零相关。ICIR 使用历史 RankIC 均值除以总体标准差，未年化，标准差为零时为空。

按因子值排序划分等数量组，组数同时受最大组数和每组最少证券数限制。默认五只证券最多形成两组，三只不足以形成两组，不强行展示 Q5−Q1。图表使用“最高组−最低组”；收益未扣成本、不处理融券可得性，不等于真实多空组合净收益。

滚动窗口不足时留空；预先固定的前后段用于稳定性对照，不冒充模型训练和选择后的样本外绩效。重叠的多日前瞻标签具有时间依赖，样本数量不等于独立观察数；当前没有提供显著性保证。

风格暴露是价量代理间的截面秩相关，相关矩阵是最新日期的因子值相关。排序换手不是资金换手，当前容量显示未评估真实容量。

## 两个后端

内置与 Qlib 接收同一个因子面板及标签。Qlib 在独立解释器中执行真实 calc_ic，多个前瞻周期合并成一次工作进程调用；返回后统一转换为平台未年化 ICIR。显式选 Qlib 时不静默回退。

Qlib 信号分析不需要每次训练模型；原生训练/组合 Workflow 的 qrun、provider、模型与产物是单独的能力和验收项。环境诊断真实调用选定工作进程，而不是仅查看 Web 进程能否发现模块。

## 缓存、过程与证据

后台任务记录真实阶段、完成或失败；页面只在运行期间轮询，结束后停止。结果缓存由股票池版本、观察日、后端、数据源、配置和实现内容共同确定；原始因子数值复用项目内缓存。

指标和告警按池版本、因子定义、周期及后端隔离。报告保存请求/加载/失败数量、覆盖、参数、日期和口径，不能用行情加载成功后的子集美化覆盖率。使用流程与截图见[通用因子监控](../usage/factor_monitoring.md)。

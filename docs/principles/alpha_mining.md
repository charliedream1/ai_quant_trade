# Alpha研究纪律与三类Agent

本系统将假设挖掘、主题关联和体制配置分成三种有不同输出含义的研究流程。角色名称参考公开机构方法，实现、数据和门槛由本项目独立管理，不代表Man Group或JPMorgan原版系统。

## 角色与确定性边界

Idea Person提出预先机制、反假设、方向、字段与失效条件；Implementer生成受控算子树和审阅Python；Evaluator读取真实数值与账本，检查经济逻辑和一致性。编排器是状态机，保存预算、冻结、取消、失败和证据，没有能覆盖硬失败的模型主席。

模型采用普通OpenAI兼容生成、文本ReAct和json_repair。真实读取哪些工具证据都有记录，未知引用不能直接采信。可选的enable_thinking扩展只在显式配置时发送，默认不影响既有服务。

生成代码不在主进程eval/exec。登记算子负责计算，假设、定义、生成源码和结果共享摘要。未知算子是技术失败，不把代码语法通过当作隔离或正确性证明。未来扰动、独立算子单测和证券排列检查提供不同层面的验证。

## 研究家族与统计

人工与AI使用同一政策，运行前冻结母池、数据、候选预算、方向、持有期、统计量、成本和研究切分。失败、中断和参数变体全部保留，原假设不能被成功结果覆盖。

训练、验证和最终留出按日期分离；持有期标签跨边界时剔除，边界加入预登记隔离。横截面同日作为整体，日度RankIC与净超额采用日期移动区块重采样，显著性以零假设中心化，区间和p值分别记录。两个主检验的家族按Holm方法校正，包含预留未成功槽位；常数及样本不足不给出伪显著性。

此校正不消除无限次读取验证结果后的自适应搜索偏差。系统拒绝在相同证券与重叠已读日期上换项目重做“未见验证”；最终留出只消费一次，失败/中断也不重新解锁。它是本地研究纪律控制，不是阻止拥有数据库修改权的人篡改结果的安全认证。

参考价量因子定义在研究创建时冻结，验证报告给出同日横截面Rank相关及有效日期数，实际账本另给策略与等权基准日收益相关。它们用于识别重复暴露，仅是描述诊断；未覆盖全策略库，也不是独立Alpha或增量收益的证明，不据此追加参数搜索。

## 交易和资料时点

因子只读取历史窗口，标签从下一开盘到后续开盘；实际组合复用现有账本、Portfolio、Risk与成本政策。配对基准用相同日期、行情母池、佣金/税费/滑点与风险约束；价格参考线与扣费基准分别说明，不把分组收益当账户收益。

资料区分观察期、发布、可得、修订版本和系统入库。宏观选择截止/滞后时点可用版本，不能用今天修订值加shift伪装PIT。主题词表不能早于其冻结可得时间使用，当前资料不能变成过去的主题池。用户核验创建新数据版本，不改已冻结研究。

体制模型只接触相对期、数值、受控ID和固定定义。服务端保留真实映射，模型上下文不包含绝对日期、文件名及事件信息；资料不足弃权。四体制映射到固定资产权重，资金余量保持现金，硬风控不参与投票。八个模型/推理配置是独立实验配置，不代表统计独立或八专家共识。

当前模型可能训练过历史样本。因此输入时点检查通过，仍不能声称模型真正没见过历史；回放、冻结后前向观察和实际资金表现分开。ALFRED按请求版本取得的快照能证明可得版本，但用版本日期上界时需披露其不是每条原始发布日期。

## 晋级、存储与复现

统计、技术、真实来源、覆盖、风险、成交和执行能力共同构成硬门槛。经济与技术两轨人工意见引用同一产物摘要，不能覆盖失败；合成资料即使演示政策允许计算也不能导出生产候选。通过后只导出工坊草稿，发布、组合变更及实盘启用仍需现有流程和新的验证。

研究的源文件、配置、数据和产物摘要随版本保存；事件采用顺序摘要链，后台任务仅允许有界并发。进程中断明确失败，不默默重启试验。摘要链提供修改检测，不是外部签名、不可篡改存储或双人身份认证。

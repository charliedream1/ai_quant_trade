# AI、CLI 与多 Agent

## 本地 Skill 洞察报告

智能洞察的两个固定任务实际加载 `src/skills/` 中从本机 WorkBuddy 复制的方法与参考，SHA-256 随运行留档。YAML 固定提示词覆盖上游机器路径、发布及安装要求；不执行原始脚本或读取用户目录 token。

独立服务先采集带来源的数据，再通过模型 API SSE 或 Codex JSONL 生成正文；模型使用普通文本 ReAct 读取白名单 Skill 和证据，JSON 经 json-repair 解析。工具观察与公开正文按实际发生时间追加 JSONL；后台任务去重且限制并发，页面离开不销毁任务。

正文必须有指定章节和有效证据标识，程序只核验结构与引用存在性，不声称完成逐句事实验证。市场月度历史、全部 23 项技术指标及部分机构数据未接入，报告保留缺口和 `partial` 状态。受控模板转义模型文本，图表只读取程序证据，预览 iframe 使用独立来源沙箱，HTML 下载作为附件。

入口与配图见 [Skill 洞察报告](../usage/insight_reports.md)，正式设计见项目 `doc/agents/insight_skill_report_design.md`。

## 三种调用链路

| 链路 | 行为与边界 |
| --- | --- |
| 普通模型问答 | 通过 OpenAI 兼容 API 调用已配置模型；不自动拥有工作台会话与工具上下文 |
| GenericAgent 工作台 | 普通文本 ReAct 生成动作，解析后执行已登记工具，再读取观察；JSON 使用 json_repair，不依赖 function call |
| 本地Codex/Qoder CLI | 实际子进程按原生事件更新；可用性取决于服务机器的程序、认证及参数，默认只读，允许显式项目编辑 |

GenericAgent 当前调用完成后回传工具动作与正文，不逐 token 更新。原生CLI逐事件更新，但没有事件时不编造进度。TRAE现按旧版/2.0区分协议，CodeBuddy须安装实际CLI；WorkBuddy桌面账户不自动互换。旧策略产物模拟器不是实际对话后台。研究生成与原生Skill双向执行的约束见[统一后端原理](agent_cli_skills.md)和[使用指南](../usage/agent_cli_skills.md)。

Qoder通过print与stream-json传输公开正文和工具事件，增量、完整消息及最终结果去重，不展示隐藏思维。认证检查缓存与模型列表按需刷新；未认证或检查失败时不发起模型对话。超时与失败保留实际原因，不能把安装成功写成真实回复成功。

同一输入区用于主工作台和悬浮问答。访问权限由能力目录、业务层与实际CLI参数共同约束：API的项目工具仅支持读取，Codex使用sandbox；Qoder通过dont_ask/accept_edits和Read/Glob/Grep及可选Write/Edit，不提供Shell或外部MCP。Qoder工具权限不等于操作系统隔离，不能将项目编辑或不询问解释成无限制访问。消息记录所选后端、权限和模型/强度；旧请求未传权限时仍为只读。

## 会话与附件

主工作台会话、消息、后台结果和附件元数据会留档，同一会话限制并发发送。附件先按扩展名、数量、大小及文本预算处理；图片能否理解取决于实际模型。服务端返回附件标识，客户端路径不能当成远端服务器路径。

mock 行情和模型来源是不同维度；mock 服务默认不启动真实 Codex，显式门禁只允许执行，不完成认证。悬浮助手保留显示与多轮上下文，但不能当作主工作台持久会话目录。

## 四角色研究复核

分析、风控、复核、汇总按顺序读取指定回测与前序意见。每个角色保留工具轨迹、证据、状态和耗时；真实模型、返回协议或预算不满足时失败。ETF 工作流额外核对池、成本、换手及跟踪误差。

研究结论不执行下单，也不能绕过硬性风险条件。多角色对同一不完整数据的一致意见不是独立事实验证。操作见[AI 工作台](../usage/ai_workspace.md)与[ETF 指南](../usage/etf_research.md)。

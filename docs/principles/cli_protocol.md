# 平台 CLI 协议

CLI 是已启动后端的 REST/SSE 客户端，与网页共用领域服务、参数解析和持久化。它不在本地重写一套回测逻辑，也不自动启动服务。

## 请求与结果

命令解析、配置、请求拼装、操作边界检查、传输和结果渲染依次进行。输入日期使用 JSON 兼容字符串；覆盖时保留零和 false。配置文件、完整请求与策略参数文件分别承担连接、业务请求和参数内容。

| 结果 | 解释 |
| --- | --- |
| HTTP 成功 | 传输成功，仍可能包含业务失败 |
| code / message | 服务端业务响应，结合 data 检查 |
| 执行状态 | failed 或 blocked 在执行命令中映射非零退出 |
| 查询旧失败任务 | 查询本身可以成功，data 中保留失败状态 |
| require-real | 拒绝模拟来源及缺少来源证据的结果，不补齐数据 |

stdout 输出结果，诊断日志走 stderr；JSON 供脚本解析，JSONL 仅转发真实事件。超时、断流或中断不保证同步服务端操作取消，因此写操作不会盲目自动重试。

分页接口的全量读取有数量上限并注明截断；检索接口不一定支持翻页。导出只写项目内，CSV 当前用于成交，已有文件需要显式覆盖。删除、重置和交易能力遵守客户端及后端共同检查，通用 API 调用不能绕过。

操作及退出码见[命令行上手](../usage/cli.md)与[完整参考](../usage/cli_reference.md)。正式设计保留在项目 `doc/12_cli_interface_design.md`。

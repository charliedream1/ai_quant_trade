# 关系图谱原理说明

## 建模目标

关系图谱不是单纯把股票连起来，而是帮助用户判断“这只股票和哪些资产、主题、事件有关，以及关系强弱和来源是什么”。因此图谱需要同时服务研读、推荐、风险解释和后续策略构建。

## 关系类型

| 类型 | 原理 | 使用价值 |
|------|------|----------|
| 行业 | 同一行业或板块内公司通常受相近基本面和政策变量影响 | 快速识别同业可比标的 |
| 概念 | 共同题材会在主题行情中形成短期联动 | 支撑题材热度和轮动观察 |
| 产业链 | 上下游关系传递需求、成本和供给冲击 | 解释事件影响路径 |
| 股东/机构 | 共同股东、基金重仓和机构持仓反映资金偏好 | 辅助识别资金风格暴露 |
| 新闻共现 | 多个标的出现在同一事件中，说明短期信息关联 | 适合事件驱动分析 |
| 收益相关 | 历史收益率联动反映统计相关性 | 可用于组合分散、风险聚类和联动监控 |

## 展示原则

- 中心股票必须始终可见，即使筛选后没有边。
- 边需要展示关系类型、权重和说明，避免用户只看到“有线”却不知道原因。
- 节点大小可反映度数，但不能让中心节点失去识别度。
- 关系类型筛选要先服务可读性，再服务完整性。
- 图谱摘要需要说明节点数、边数、主导关系和筛选条件。

## 后续演进

当前已提供显式关系、收益相关和证据展示。最小生成树、实体语义模型、行业政策影响推断及动态多关系模型仍属后续扩展，未将简单共现称为因果关系。

## 当前实现与证据

真实新闻先按代码查询候选，再检查标题/摘要中的证券实体，或采用来源原有的证券标记。查询时主动写入的代码与关键词不能反过来作为命中证据。同文共现要求同一文章同时支持相应实体；关系保留标题、来源、发布时间、链接、片段、命中字段和提取方法。只拥有标题与摘要时不声称分析了全文。

服务层不再把市场前三条新闻、强势板块、任意候选股票补成事实关系，也不为达到所选深度补足链路。深度只是最大探索跳数，数据不足时保持浅图或空边。模拟数据仍用于演示，但来源明确标注，不能混为真实关系。

收益相关边使用真实日期对齐的收益区间，起点和终点均相同才配对，避免把停牌后的两日收益与其他证券一日收益混算。展示相关系数正负、日期范围和有效样本；边宽可按绝对强度变化，反向关系另用颜色和文字标识。价格水平相关不再称为收益相关。

布局按实际节点范围留边，稀疏层分散排列。图例采用左锚点，避免右锚点在左侧造成自动边距；切页、导航折叠和窗口变化后可重新适配。选择关系可查看安全转义后的证据，原文只允许 HTTP/HTTPS 链接。

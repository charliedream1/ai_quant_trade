# 02 股票、指数与ETF

目标：识别交易对象与比较对象。前置：[研究流程](01_research.md)。

## 核心概念

股票代表公司权益；指数按编制规则汇总一组资产，通常作为观察或基准；ETF是可交易基金，有基金份额价格、净值和跟踪目标。指数点位不能直接当成可成交的ETF价格。

ETF价格相对净值可能折溢价。跟踪同一指数的不同ETF，其费率、流动性、成交价差与跟踪误差也不同。交易单位、可交易时间、涨跌幅、结算和申赎规则取决于市场与产品，应按研究日期查交易所及基金公告。本章不把某一市场规则当成全球通则。

## 公式与合成例子

折溢价率 = 交易价格 / 同时点参考净值 - 1。示例：价格1.02、参考净值1.00，溢价约2%；若参考净值是较早时点，该比较还混入了时间差。

两只ETF分别跟踪同一指数，持有各50%不意味着获得两个独立风险来源。还需分析底层资产重合与收益相关性。

## 易错点

把代码当整数会丢失前导零；跨市场同代码可能对应不同证券；指数名单与可交易标的列表不能混用。历史回测也不能使用当时尚未上市的ETF。

## 练习与答案

练习：指数上涨1%，ETF只涨0.8%，是否一定是数据错误？

答案：不一定。先对齐时点、收益定义、分红与复权，再检查跟踪误差、折溢价和费用。单日差异不足以判断数据或产品质量。

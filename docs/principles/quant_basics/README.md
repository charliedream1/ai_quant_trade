# 量化基础课程导读

目标：读懂策略、回测与风险结果，能指出一次研究的证据和局限。前置知识：基础四则运算；统计与编程知识可边学边补。本课程是原理教学，不是投资推荐，示例数字均为合成教学数据。

## 学习顺序

先学习研究流程、交易标的与数据，再学习收益、统计和因子；之后学习信号、回测、组合和模型，最后完成轮动研究与模拟复盘。应用左侧“学习空间”提供同一课程的目录与前后章节按钮；这里也可通过 MkDocs 阅读。

## 一个最小研究例子

合成例子：在时点t比较三项资产过去20个交易日收益，只选择正收益资产等权持有，t+1尝试成交；若没有正收益，保留现金。完整证据应包含当时资产池、输入日线、信号、目标权重、订单、成交和费用。“选中了什么”与“实际买到了什么”分别核对。

## 易错点与练习

收益漂亮不等于假设成立；界面显示完成不等于历史覆盖完整；测试模式不是真实行情。先学会核对口径，再比较算法复杂度。

练习：只有净值截图，没有标的、日期和交易记录，能复现研究吗？

答案：不能。至少还需数据来源/时点/复权、参数与版本、请求及实际日期、基准、订单成交和费用。下一章开始把这些项目组织成研究流程。

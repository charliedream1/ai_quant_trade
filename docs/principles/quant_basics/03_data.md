# 03 行情与历史时点

目标：分清“今天知道”与“当时知道”。前置：[标的类型](02_instruments.md)。

## 核心概念

OHLCV是开盘、最高、最低、收盘和成交量。交易日历排除休市日，不能用工作日简单替代。缺失可能来自上市时间、停牌或数据源故障，不能一律补成零价格。

复权用于处理分红拆股等价格跳变，但复权因子和时点会影响可复现性。信号计算口径与实际成交口径应明确区分。Point-in-time要求信息在决策时已经可得；财务期末日期不是公告可得日期。用今天的指数成分回测多年历史会引入幸存者偏差。

## 合成例子

某资产7月1日收盘100，拆分后7月2日价格50且份额翻倍。未复权价格直接计算得到-50%，但资产价值并未因此减半。另一资产7月2日停牌，不能把缺失价记为0，也不能生成一笔可成交订单。

## 易错点

“请求1月至6月”与“实际取得1月21日至6月30日”是不同覆盖。读取最近120条再过滤旧日期不能保证取到所需历史。平台按日期请求，并保留真实日期和覆盖证据；覆盖不足时应解释，不能报告完整完成。

## 练习与答案

练习：周六无日线是否算缺失？历史名单没有版本时是否能称为历史指数池？

答案：先按该市场交易日历判断周六是否开市；普通休市不算缺失。没有历史成员证据，只能说明使用当前名单，不能冒充历史指数池。

# 09 组合配置与风控

目标：区分信号强度、目标权重与实际仓位。前置：[信号](07_signals.md)、[执行](08_execution.md)。

## 核心概念与公式

组合配置决定资金如何分配，风控决定哪些风险可以承担。常见研究方法有等权、逆波动权重和风险预算；需要比较输入稳定性、约束和交易成本。组合预期收益是权重与资产收益的加权和；方差还取决于资产间协方差，不能只平均单项波动。

约束可包括单资产/行业上限、总暴露、现金保留、止损和回撤阈值。子策略先生成目标，再净额合并并经过组合层风控。相反方向的子策略不能被当成两份独立可用现金。

## 合成例子

两项资产原始分数2与1，归一化得2/3与1/3。若单资产上限40%，不能简单截为40%与33.3%后把剩余资金随意塞回第一项。应按配置继续分配或保留现金，并记录最终暴露。

资金10000、某资产目标权重30%、价格20，理论数量150；实际需按交易单位、费用及可用现金向下调整，所以实际权重可能低于30%。

## 易错点

止损在跳空时不保证成交在阈值价；风险平价不等于收益平等；组合并行不自动消除底层重仓重叠。风险约束应在目标与执行阶段都留证据。

## 练习与答案

练习：三个子策略各分配80%到同一资产，账户能买入240%吗？

答案：不能默认如此。先明确子策略资本预算，合并净目标，再应用账户总暴露、单资产上限和现金约束；杠杆能力不能凭空假定。

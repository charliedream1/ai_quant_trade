# 05 统计、波动与回撤

目标：将收益与不确定性一起阅读。前置：[收益口径](04_returns.md)。

## 核心概念与公式

均值概括位置，标准差概括离散程度；极端值与样本数量会影响两者。日收益波动年化常按日标准差乘年化交易日数的平方根，但依赖稳定性等假设。Sharpe通常是超额收益均值除以标准差并按频率调整，需说明无风险收益和年化因子。

回撤 = 当前净值 / 此前历史最高净值 - 1。最大回撤取整个区间最深值，反映路径风险。相关系数衡量线性关联，不证明因果，也不保证危机时期稳定。比较资产相关性应对齐同一日期的收益，不能将两个上涨价格序列当成收益相关性。

## 合成例子

净值100→120→90→108，峰值120，最低90，最大回撤为-25%；最终累计收益8%。期末盈利与期间深回撤可以同时存在。

三次收益1%、1%、1%的标准差为0，不能据此给出“无限优秀”的Sharpe。应显示不可计算或说明样本不足。

## 易错点

少量样本、异常值、重复试验和不同频率都可能使指标不稳。雷达图是压缩展示，先查看各维度定义、标准化方式和缺失项，不把面积当成统一绩效分数。

## 练习与答案

练习：两条价格曲线相关性很高，能证明分散无效吗？

答案：不能。先用同区间收益重新计算，检查样本和市场阶段；价格共同趋势可能形成伪相关，相关性本身也无法描述全部尾部风险。

# 07 趋势、反转与轮动

目标：写出具有决策时点的明确信号。前置：[因子](06_factors.md)。

## 核心概念

趋势规则假设一段行情具有延续性，反转规则假设偏离会回归，轮动规则比较资产并重新分配资金。它们依赖市场状态和周期，没有普遍有效的一类。均线交叉、动量排名和偏离阈值都需要明确计算窗口、触发条件与持有期。

级联筛选逐步缩小候选，例如规则→模型→Agent；并行评分让多个分支对同一母池给出分数，再按一致尺度聚合。输入输出类型必须匹配；评分节点不等于仓位节点。Agent输出需要可追溯依据，并受组合风险与执行约束限制。

## 合成例子

两项资产过去20日收益为8%与-2%。规则“只买正收益且排名首位”选择第一项；若两项均为负，则现金也是一种明确定义的结果。若在t收盘确认信号，通常不能假定还能按已经过去的t开盘成交。

## 易错点

把不同量纲分数直接相加；多个相似模型投票却误以为独立证据；级联过严导致空候选但仍硬凑买入。规则变化应形成新版本，保留节点关系与每阶段淘汰理由。

## 练习与答案

练习：规则筛到10只，模型筛到3只，Agent否决全部，组合该怎样处理？

答案：按预先定义的空候选政策保留现金或维持合规旧仓，并记录理由；不能为了“有结果”偷偷放宽阈值。

# 04 收益、复利与基准

目标：使用一致区间比较净收益。前置：[行情时点](03_data.md)。

## 公式

简单收益 r = 期末价值 / 期初价值 - 1。累计收益 = 各期(1+r)连乘 - 1；多期收益不能直接相加。年化收益 = (期末/期初)^(年化交易日数/实际交易日数) - 1，需明确日历、期间及现金流口径。很短的样本年化会被放大，不能代表未来一年。

基准应与资产池、币种、风险暴露、时间和复权口径一致。超额收益可以是累计收益差，也可以是相对净值增长率，应注明定义。账户有入金出金时，简单期初期末比例会混入现金流，需要另外选择时间加权或资金加权方法。

## 合成例子

本金100，先涨10%得到110，再跌10%得到99，累计收益为-1%，不是0。策略收益8%、基准6%时，收益差为2个百分点；相对净值增长为1.08/1.06-1，约1.89%。

## 易错点

展示毛收益却遗漏手续费、滑点与税费；策略只有部分交易日而基准覆盖完整；把未成交的目标收益当成账户收益。核对最终资金时，未平仓资产和末日平仓费用也要一致。

## 练习与答案

练习：亏损20%后需要上涨多少才能回本？

答案：原值100降至80，需要100/80-1=25%。这也是控制损失和使用复利口径的原因。

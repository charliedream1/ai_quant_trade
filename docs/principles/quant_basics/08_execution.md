# 08 回测撮合与偏差

目标：沿信号→订单→成交→资金核对结果。前置：[信号](07_signals.md)、[收益](04_returns.md)。

## 核心概念与公式

回测将当时可得信息和执行假设应用到历史。订单是意图，成交是实现；限价未触及、无流动性、交易单位或现金不足都可能造成不成交。日线OHLC不能完整还原日内路径，同一根K线内多个条件的先后顺序有不确定性。

买入现金减少 = 数量×成交价 + 费用；卖出现金增加 = 数量×成交价 - 费用。净资产 = 现金 + 持仓市值。滑点、手续费、税费、分红与停牌处理均需写明，未建模的项目不能假设已包含。

## 合成例子

10000现金，以10元买100股，买入费率0.1%，扣1001元后剩8999。之后以11元全部卖出，卖出费率同为0.1%，到账1098.9，最终10097.9；毛价差100元，净收益97.9元。

## 易错点

用未来收盘决定当前开盘订单；使用当前成员回测历史；把不同日期的资产按行号对齐；只取最近日线后声称覆盖旧区间。平台普通策略走simple，冻结图形组合走composition；Qlib模型Workflow依赖独立数据与配置。

## 练习与答案

练习：请求1月5日至16日，曲线从10月开始，但任务显示完成，可以接受吗？

答案：不可以。实际日期必须在请求区间，并按交易日历检查覆盖；失败或缺失需要保留任务、参数和原因，不补假K线。

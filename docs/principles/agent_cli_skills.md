# 统一生成后端与原生Skill原理

本实现分为生成边界、领域编排和原生宿主入口三层。生成边界支持API、Codex、Qoder、TRAE和CodeBuddy协议；领域编排继续持有证据、传统文本ReAct、json_repair、预算及结果门槛；原生Skill只启动已有领域流程。使用步骤见[操作指南](../usage/agent_cli_skills.md)。

## 研究边界

只读沙箱限制写入，不等于模型没有联网、MCP、隐式Skill或额外资料。严格研究资格与程序安装、账户认证和普通聊天能力分开记录。当前Codex及旧TRAE无法证明关闭全部原生能力，所以不接受为严格研究角色；Qoder按已核验版本使用空工具、空配置来源、空MCP和替换系统提示，并再次核查初始化事件。未知原生事件、工具调用或流式工具参数都拒绝，不将它们当作平台的研究观察。

该约束不会消除模型训练记忆，历史实验仍标识记忆风险；PIT资料不足时沿用原阻断规则。CLI没有额外启动HTTP模型服务，平台也没有改用function calling或强制结构化输出。

## 身份与过程

冻结的身份包括后端协议、实际模型/强度、配置摘要和可得程序版本/文件身份。API不存明文Key；CLI不复制用户账户。执行时核对身份，防止旧成绩在后端或模型变化后默默复用。原有共享调用预算、统一交易成本、经济/技术双轨复核、原文引用和一次性留出保持有效。

过程区保留实际可见模型正文、平台证据观察、原生状态和错误。未知usage不记作零，外层CLI宿主账单不混入平台子调用统计。失败时没有真实模型结果就不能生成成功研究结论。

## 本地与网页的一致性

本地执行器直接调用InsightReportService、ResearchTeam、AlphaService、AgentStrategyService和PipelineService，保留业务运行ID。十个Skill共享一个执行器，配置和预置映射在YAML；同一请求在本地、网页或显式远程模式遵循相同领域约束。

本地任务属于前台进程，运行状态和产物可跨终端读取，但不承诺进程退出后继续运行。取消按底层服务的有界请求处理。模型提供子进程带递归标识，不能反向启动同类研究Skill；原生Skill宿主和模型提供者承担不同职责。

## 分发

规范Skill源与三个宿主目录之间采用摘要清单和普通复制，避免Windows符号链接依赖；预检全部同名目标后才写入。未知或被用户修改的内容不覆盖，不删除旧文件。TRAE原生发现路径未核验时，只提供显式加载及本地执行方式。

协议依据来自各工具官方文档和本机帮助；没有复制第三方量化项目实现或提示词。完整范围、可用性限制及验收标准见27号正式设计和本轮验收记录。

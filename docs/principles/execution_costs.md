# 执行成本、撮合与快照

普通事件回测与图形组合共用执行成本模块，保留各自的信号和组合账本。同一费用假设进入实际成交、现金与损益，并能从冻结配置追溯。操作配图见[费用设置指南](../usage/backtest_execution.md)。

## 从配置到实际扣费

配置按“兼容旧执行参数 → 选定方案 → 本次显式覆盖”解析。空输入不覆盖，数值零是有效覆盖；整数、有限数值、比例范围和规费包含关系统一校验。方案中的税费生效表按成交日期解释，显式覆盖优先于日期表。配置含来源、版本、适用日期与摘要。

成交先判断历史状态、批次可卖数量、过去量能参与率、成交单位、限价与现金。滑点沿买贵卖便宜方向影响成交价，可选比例或最小价位数；超过委托限价则不成交。资金可买数量同时考虑最低佣金及各项费用。

佣金以外部订单为单位累计计算，后续成交仅补收未支付的增量；税费按每次成交的有效费率计算，不用新税率追溯重算旧成交。金额按配置精度用十进制取整。

组合内部调拨不产生外部手续费；净外部订单成交后，将真实数量和费用分摊到各子账本，尾差受剩余金额约束。部分平仓按实际平仓比例结转开仓成本，剩余仓位保留未结转部分。

## 费用与收益的勾稽

实际现金 = 上期现金 − 买入成交额 − 买入费用 + 卖出成交额 − 卖出费用。净资产还包括期末持仓市值；结算未到期或未成交的仓位不会被当成现金。

总执行成本拆分为佣金、税、过户费、其他费用和滑点归因。滑点已进入成交价格，只展示其归因，不再次扣款。加回成本损益 = 实际净损益 + 这些成本，是固定实际成交路径的归因。

重新运行零费用假设可能改变数量、资金可用性和后续交易，因此零成本实验是独立反事实，不能用加回成本指标代替。两种结果均保存各自配置和行情摘要。

## 可用时点与数据能力

结算按买入批次和观察交易日推进；容量使用此前窗口量能，不读取当日收盘后才完整可知的成交量。交易状态须有对应日期及可用时间，不能将未来收盘状态用于当日开盘决策。

共享历史加载对新取数和旧缓存均统一成交量单位：东财日线的“手”按配置换为股，腾讯与BaoStock适配器已有股数不重复换算；原始归档保持不变。东财单位依据[AKShare官方历史行情说明](https://akshare.akfamily.xyz/data/stock/stock.html)，倍率配置在`egs/backtest.yaml`。容量计算不能把股数和手数混用。

研究模式记录缺口；严格模式检查交易状态字段、披露时点及逐日权益事件确认。缺失、未来信息或尚未实现的非空公司行为事件会阻断。当前没有完整分红送股账户处理，不能把“没有字段”解释成“历史无事件”。复权价格研究也不等于原始价格账户模拟。

历史状态与量能只是日线模型的一部分；盘中触价顺序、限价队列和真实冲击仍无法完整还原。

## 策略与执行实验分别冻结

策略版本决定信号、结构及组合风控规则。回测费用作为独立实验输入保存快照，不原地修改策略版本或旧任务。普通/一键/API/CLI/图形入口复用解析和撮合；旧任务缺少拆分时保持原结果。前向模拟沿用冻结规则，本轮不接受临时费用覆盖；QlibWorkflow沿用自身配置，不冒充共享成交账本。

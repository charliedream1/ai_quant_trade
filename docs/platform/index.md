# AIQuant智投帮助中心

后续开发以当前仓库根目录为准；[新仓库启动、文档合并及发布](migration.md)说明入口和迁移边界。平台说明以docs文档为准，旧all_in_one根README不再复制。

文档分为两个入口：先按使用文档完成操作，再按原理文档理解指标、处理过程与能力边界。

知识库新入口为“知识库入库 / 知识库问答”，支持命名库、文件检索与来源预览，操作及项目内搜索依赖安装见[知识库指南](../usage/knowledge.md)。

第一次使用`src`应用，先看[一体化工作台使用指南](../usage/workspace.md)：环境、启动、九模块入口、第一轮回测、AI/知识、CLI及排障按操作顺序集中说明，并配实际页面动图。

| 入口 | 适合解决的问题 |
| --- | --- |
| [使用文档](../usage/README.md) | 怎样启动、看行情、导入策略、调参、回测、使用 AI 和 CLI；关键操作配截图 |
| [原理文档](../principles/README.md) | 数据怎样流转、指标怎样计算、信号怎样执行、模型与多 Agent 如何工作 |

首次使用建议按 [快速上手](../usage/quick_start.md) → [导入策略](../usage/strategy_import.md) → [参数预览](../usage/strategy_parameters.md) → [回测与核对](../usage/backtest.md) 的顺序完成一轮。对话与附件见 [AI 工作台](../usage/ai_workspace.md)，终端操作见 [CLI](../usage/cli.md)。

操作截图取自实际页面，配图说明记录日期与数据模式。模拟行情和模拟回答只用于演示流程；指标、来源和能力状态以实际运行结果为准。

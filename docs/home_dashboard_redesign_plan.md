# 首页信息层级与图表改造方案

日期：2026-10-17；状态：用户已确认，首页布局、图表、数据口径与色阶改造已实施；验收结果见 `docs/audit/home_dashboard_2026-10-17.md`。技术路线继续使用模块化 Gradio、Plotly 与现有业务服务。

## 当前问题与定位

- `src/frontend/features/dashboard.py:render_dashboard()` 中，AI 大卡与新闻出现在主要持仓、风险和净值图之前；总览连续展示十一张明细表，缺少图形化摘要与阅读优先级。
- `src/frontend/service/dashboard_views.py:_dashboard_kpis_html()` 将同一组卡片同时用于 KPI 和“市场驾驶舱”；`_dashboard_focus_html()` 再次展示账户资产、今日盈亏和持仓，首屏被重复信息占用。
- `_dashboard_meter_width()` 把金额、数量等不同单位转换成无统一业务含义的装饰进度条，容易让用户误以为是风险或完成比例，建议替换为真实占比或阈值。
- 已有净值、盈亏和板块排名图，但位置偏后，资产配置、持仓贡献和风险占用主要仍以表格表示。
- `src/frontend/service/dashboard.py:dashboard_market()/dashboard_account()` 仅为部分数值列包装色阶；`foundation.py:_gradient_cell_style()` 采用正绿负红，与当前 A 股红涨绿跌的图表约定不一致。
- `src/frontend/theme.py` 为表格单元格、斑马纹与悬浮行设置的强制背景，存在覆盖色阶的风险。实施时必须检查浏览器最终单元格样式，不能仅验证返回了样式对象。

## 按重要性排列的页面

| 顺序 | 要回答的问题 | 展示与面积安排 |
| --- | --- | --- |
| 顶部控制与异常 | 当前数据是否可用，有无优先处理事项？ | 账户视角、刷新时间、数据来源保持一行；高优先级事项显示紧凑告警，并提供对应模块入口 |
| 第一行核心指标 | 我的账户现在怎么样？ | 只保留一组总资产、今日盈亏、累计收益、仓位、当前回撤；数据不足的指标明确显示缺失状态 |
| 主图区域 | 变化趋势是什么，资金如何分布？ | 左侧约三分之二为账户净值/收益趋势，右侧为现金与持仓配置环图，附仓位与单票集中度的真实数值及阈值条 |
| 市场与持仓 | 今天哪里强弱，我的持仓受什么影响？ | 左侧板块涨跌热力图，右侧持仓盈亏贡献横向条形图；关键指数使用紧凑涨跌卡 |
| 执行与行动 | 有什么必须处理，策略是否正常？ | 前三至五项按优先级排序的待办、策略/定时任务状态分布，以及小型 AI 入口 |
| 辅助内容与明细 | 需要进一步核实时看哪里？ | 最多三条新闻摘要；持仓、自选、指数、订单、风险与任务等完整表格默认折叠，保留原有查询与刷新功能 |

1440×900 窗口目标：控制区、异常、核心指标和主要趋势图在首屏可见；首页允许内容区自然滚动，不把全部图表压缩到一屏，也不沿用 AI 主界面的整页禁滚动规则。较小窗口按重要性单列排列。

## 图表的数据与语义

- 净值/收益使用账户已有历史，不使用补齐曲线伪造历史；历史足够且口径可对齐时才展示回撤或基准比较。缺少基准数据时不绘制基准线。
- 资产配置按真实现金、持仓市值构成；零持仓显示现金占比，账户未创建显示引导状态。实盘仅有配置资金时，明确标记配置口径，不能作为 broker 实时资产或真实收益。
- 仓位与集中度采用实际比例及已有风控设置，新增展示参数统一放 YAML；不生成没有业务依据的综合风险分或大量速度表装饰。
- 板块热力图保留实际数据覆盖范围和时间：现有接口只返回部分板块时标记为样本，不宣称全市场广度。没有有效规模字段时等面积展示，不把涨跌幅兼作面积。
- 持仓盈亏贡献仅在数据足以计算时绘制，并注明浮动盈亏或当日盈亏口径。不能把浮动盈亏当作当日贡献，空值不视为零。
- 概览与详细图表使用同一账户和估值口径，修复“成本估算摘要”和“市值明细”可能不一致的问题；估算、滞后和缺失数据有可见说明。

## 表格色阶

| 字段类型 | 颜色规则 | 可读性约束 |
| --- | --- | --- |
| 涨跌幅、收益率、盈亏 | 本项目现有 A 股约定：正红负绿，零为中性；同列以零对称，颜色越深绝对变化越大 | 保留正负号、百分比和单位；极值截断色深不截断原数值 |
| 市值、成交额、仓位 | 蓝色单向色阶或单元格数据条 | 不将高市值或高成交额直接标成风险 |
| 风险占用、阈值 | 正常/关注/超限分级，并附状态文本和真实阈值 | 与收益色阶区分，缺失值显示中性占位 |
| 任务与委托状态 | 状态徽标与严重程度色 | 不对 ID、日期、股票代码应用数值色阶 |

主题色阶必须在亮暗模式、斑马纹与悬浮行下保持可见，普通文字对比度至少 4.5:1。首轮覆盖首页及自定义仪表盘复用表格，公共样式变更需回归其他模块；不改变业务数值、排序和导出。

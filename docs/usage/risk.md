# 风险边界

## 投资风险

系统展示的行情、关系、推荐、回测、因子分析和问答均用于研究辅助，不构成投资建议。公开数据源可能延迟、缺失、限流或字段变化；推荐理由不代表因果关系；回测可能存在过拟合、幸存者偏差、交易成本低估和撮合假设偏差。

## 实盘边界

真实资金交易前必须接入合规券商通道、权限控制、风控规则、人工确认、订单回报、持仓同步、对账闭环和完整审计日志。当前系统中的实盘页面更偏运行配置、dry-run、状态机和风控演示，不能直接替代生产交易系统。

## 数据边界

真实行情模式依赖外部公开接口，网络、代理、频率限制和接口变更都会影响结果。mock 模式适合开发测试和页面回归，不应作为真实投资决策依据。

## 知识库边界

知识库问答依赖检索命中文档和模型生成质量。远程资料通过已配置 MCP 工具拉取或同步后参与检索，不能据此推断所有远程内容都已实时更新。回答需要结合引用来源复核；扫描版 PDF OCR、旧版 `.doc` 和研究包证据链仍属于后续增强项。

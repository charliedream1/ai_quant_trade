# 质量工具参考资料

## 测试与检查工具

| 工具 | 项目用途 | 当前注意事项 |
|------|----------|--------------|
| pytest | 单元测试、集成测试、接口冒烟和前端服务回调测试 | 测试目录已按 `api/core/data/frontend/agent/engine/strategy` 分类 |
| ruff | lint 与格式化检查 | 全项目仍有历史 lint 债；本次优先保证改动范围通过 |
| mypy | 类型检查 | 当前 `mypy src` 已通过；第三方缺失类型桩通过项目配置忽略 |
| pip-audit | 依赖漏洞审计 | 当前联网查询 PyPI 可能受代理影响；失败时需要记录具体网络错误 |
| gitleaks | Git 历史与工作目录密钥扫描 | 当前验证版本为 `8.30.1`；配置位于 `.gitleaks.toml`，默认继承官方规则并排除本地运行文件、缓存和审计截图 |
| Playwright | 页面点击、截图和视觉巡检 | 用于人工式逐页点击、截图留档和缺陷记录 |

## 本项目测试分层

| 层级 | 目标 |
|------|------|
| 单元测试 | 服务函数、数据处理、CLI 构建器、图谱处理等可隔离逻辑 |
| 集成测试 | FastAPI 路由、数据库、文件存储和领域服务协同 |
| UI 冒烟 | Gradio 页面能加载、标签能切换、关键按钮可点击 |
| 视觉巡检 | 截图确认布局、遮挡、空白、表格和图表可读性 |

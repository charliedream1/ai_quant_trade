## 页面巡检

页面巡检优先关注：

- 主标签和子标签能否正常切换。
- 表格是否有数据、是否可读。
- 图表是否非空、标题和 hover 信息是否合理。
- AI 悬浮窗是否遮挡主要内容，内部标签是否可操作。
- 页面在常见桌面视口下是否出现明显溢出、重叠或空白。

# 参考资料分类

本目录按主题收集外部参考资料，供设计、实现和测试回归使用。

| 文件 | 主题 |
|------|------|
| `relation_graph_references.md` | 量化关系图谱、相关性网络、多关系股票建模和可视化资料 |
| `frontend_references.md` | Gradio、Plotly 与页面巡检相关资料 |
| `quality_references.md` | 测试、类型检查、依赖审计和日志质量资料 |

引用外部资料时，需要说明“项目中如何使用”，避免只堆链接。

## 使用建议

- 与正式架构相关的结论沉淀到 `doc/`，与实现取舍相关的说明沉淀到 `docs/principles/`。
- 外部链接应优先选择官方文档、论文或成熟产品文档。
- 若参考资料只用于某次临时排障，不需要扩大为正式设计约束。

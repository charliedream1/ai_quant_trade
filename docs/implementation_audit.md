## 结论

> 2026-10-14 前端架构更新：2026-08-30 审计中的 `/ui/` 轻量 HTML 路线已经撤销。当前唯一产品前端为 `/app/` 持久 Gradio 工作台和九个独立、延迟构建的 Gradio 模块；模块在同一顶层页面按需切换，独立直达路径继续保留，迁移期完整兼容入口为 `/legacy-app/`。前端回调已按业务域拆分，`FrontendService` 仅作为稳定兼容门面。当前结构与指标见 `docs/gradio_frontend.md` 和 `docs/gradio_modularization_plan.md`。

当前项目是一个可以启动、可以演示主要页面和 CRUD 流程的 MVP 骨架，但不能认定为规格中的功能已完整、正确实现。九个 Gradio 业务模块覆盖投研看板、市场研究、研报论文、策略构建、策略仿真、实盘、AI 工作台、知识库和系统管理；各模块拥有独立组件配置并按首次访问构建。FastAPI、WebSocket、SQLite 表结构及文档列出的业务 API 操作基本都有入口。系统设置明确 SQLite 主库、文档文件、Parquet 行情湖和 DuckDB 查询引擎的边界；市场研究支持真实数据源、关系图谱、资源池和推荐验证；AI 工作台支持 GenericAgent/CLI 后端、项目文件预览、专家协作和闭环工作流；回测、模拟交易、知识库、远程知识源和环境配置均已有可用入口。真实外部 CLI 子进程、MCP 长连接复用和更完整的证据研究流仍需继续增强。

## 已确认并修复的问题

1. `gradio==4.44.1` 与无限上界的 FastAPI、Pydantic、Hugging Face Hub 最新版本不兼容，按原依赖文件安装后服务无法启动。现已增加兼容上界。
2. 新增根目录 `start.py`，统一启动 FastAPI、Gradio、REST API 和 WebSocket，支持 `--host`、`--port`、`--log-level` 和 `--reload`。
3. 配置文档声明支持 `.env`，原实现却未读取；现已实现 `.env < 进程环境变量` 的优先级。
4. 模拟账户原来允许无持仓卖出或超量卖出，能够凭空增加现金；现已拒绝非法卖出，并将成交手续费计入现金。
5. 市场分析原来全部返回 `mock-local`；现已默认启用真实数据，主源失败时仅降级到另一真实源，无可用真实源时返回明确错误。测试通过 `ALL_IN_ONE_DATA_MODE=mock` 显式隔离。
6. 页面刷新原来同时提交 17 个 Gradio 加载任务；现已降为单个非排队总览请求，隐藏模块按 Tab 加载，并增加 GZip、静态资源长期缓存、数据源失败冷却和快照读取。
7. LLM 原来返回固定模拟文本且连接测试无条件成功；现已实现真实 OpenAI-compatible 请求、可拖动悬浮问答、模型参数配置及实际连接测试。
8. LLM API Key 原来保存在数据库；现已改为写入 Git 忽略的 `.llm_env`，数据库只保存变量名，配置界面只显示掩码。
9. 自选股原来逐只请求且证券代码用模糊正则截取；现已改为腾讯/新浪批量报价、仅对缺失标的逐只兜底，并严格区分沪深北市场及 `000xxx` 指数歧义。
10. 半成品 mootdx 接入原来会在请求前无界探测 TCP 且错误宣称覆盖前复权 K 线；现已改为显式可选、限制探测数量/超时并设置失败冷却，仅作为沪深单票报价备用。全局财经快讯也增加新浪 7x24 跨域降级。
11. 策略库原来只接受“类 + on_bar/on_tick”的单一形态；现已增加 StrategyBase 标准类、普通类端口和函数端口识别，策略详情和回测创建前会执行 dry-run 预检。
12. Qlib 运行原来只保留 qrun 返回码和输出尾部；现已从配置产物目录、输出路径和日志中解析训练指标、组合回测指标和产物摘要，并在运行列表展示紧凑摘要。
13. 模拟交易原来限价单会立即按委托价成交；现已按最新行情判断是否触发，未触发时进入“待撮合”，并提供手动撮合挂单入口。
14. 环境变量页原来只能导入和刷新；现已支持按变量名校验来源、掩码值和单项删除。模型管理页已展示调用次数、成功/失败次数、平均耗时、最近状态和最近调用时间。
15. 启动后 `/app` 访问缺少明确尾斜杠处理，且日志主要显示 uvicorn 生命周期和调度器 job_id；现已明确 `/app` → `/app/` 重定向，本地默认不设置 Gradio `root_path`，启动入口会在打印访问地址前检查端口占用，启动阶段输出文件存储、数据库、帮助文档构建/挂载、Gradio 构建/挂载、路由摘要和接口布局说明，明确 `/app/` 为同进程 Gradio 页面、`/help-docs/` 为 MkDocs 静态帮助站点、`FrontendService` 为页面回调服务、`/api/v1` 为外部 REST API 前缀。日志格式增加 channel，第三方标准库日志桥接后保留真实来源并默认不占用控制台业务视图，HTTP 成功请求只保留 DEBUG 诊断，页面回调在 INFO 输出实际业务函数、源码位置和耗时，超过 1500ms 的慢回调提升为 WARNING；外部行情请求由 `data.source` 输出 provider/host/path/状态码/耗时；代理断开、连接超时等预期网络异常只输出单行失败原因、代理继承状态和重试配置，不再刷完整 `urllib3/requests` traceback；真实行情 HTTP 只对 429/5xx 退避重试，连接/读取异常快速失败并进入冷却；浏览器 `/manifest.json` 和静态资源探测不再作为后端 404 告警。调度任务日志补充任务名、类型、耗时和摘要，控制台与 MCP stdio 子进程默认使用 UTF-8 以减少 Windows 中文乱码。前端市场切换可见入口收敛到右上角按钮，页面内仅保留隐藏 Gradio 桥接器承接刷新链路；父级模块和多数重业务子页签不再绑定重数据自动刷新，图表控件首屏不再携带默认 Plotly 空图 JSON，AI 文件预览、学习正文和专家卡片改为按需加载；关系图谱查询做日内缓存且 Plotly 边线按关系类型合并 trace，帮助页改为 iframe 嵌入 MkDocs，降低页面切换时的回调、配置序列化和 DOM 负担。
16. 关系图谱此前页面只突出一层邻接结果，且推荐候选无法沉淀为可复用观察池；现已在图谱服务输出层级、父节点、路径和层级链路表，当真实源层级不足时补充多跳观察链路；市场分析页新增资源池和证券主数据搜索，支持代码、名称、拼音、别名输入，CSV/Excel 导入可按名称解析，推荐结果可加入资源池并反向载入推荐股票池。AI 工作台一级页签默认进入轻量操作台 shell，左侧可新建聊天、打开定时任务/MCP/Skill 专页并控制项目目录，中间按入口切换专页，聊天区可选择 GenericAgent 或 CLI 后端，右侧做项目文件预览，避免切换时立即加载因子、Qlib、专家和归因等重页面。
17. 语言切换此前只做部分 DOM 文本替换，动态表格字段、状态枚举和市场状态容易出现中英混用；现已将 `src/frontend/i18n.py` 拆出 UI 词典和技术字段/枚举映射，前端 JS 同时翻译文本节点、title、aria-label 和 placeholder，并通过 MutationObserver 处理 Gradio 动态渲染内容。语言和市场改为双向约束：中文固定 A 股，英文固定美股，点击市场按钮也同步语言，避免两市数据和界面语言混用；翻译完全基于本地确定性词典，不调用模型。
18. 前端加载和切换慢的主因是 Gradio 单页组件树过大。轻量 HTML 双前端实验已经撤销，现改为 Gradio-first 多应用：九个业务模块拥有独立 URL、组件树、事件图和延迟构建缓存；旧单体由同一组 feature renderer 组合，不再维护第二份页面代码。旧单体基线为 1,341 个组件、约 1.31 MB 配置，单模块降为 94 至 318 个组件、约 0.14 至 0.38 MB。

## 验证结果

- `pytest`：136 项通过；另在 Gradio 6.x 环境完成启动、挂载和浏览器兼容验证。
- 真实数据验证：腾讯与新浪对沪深北 4 个标的的价格交叉校验一致，腾讯复权日 K 返回最近 10 个交易日且通过 OHLC 完整性校验。
- 新入口帮助、Python 编译和新增文件 Ruff 基础规则检查通过。
- 当前路由验证覆盖 `/api/v1/health`、九个 `/app/<module>/`、`/legacy-app/` 和 `/help-docs/`；历史页面截图结果仅作参考，模块化路由需要重新执行全量浏览器巡检。
- OpenAPI 暴露 112 个文档业务操作，另有 1 个 `/api-meta` 操作；接口数量覆盖不等同于业务能力已经完成。

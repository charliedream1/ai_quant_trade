# 页面完整性审计与对标改造记录

审计日期：2026-09-10

## 对标结论

参考系统侧重点如下：

- TradingView：以自选、筛选器、热力图、经济日历和资产新闻作为机会发现入口。
- Interactive Brokers TWS：把订单、图表、报价、自选、新闻、组合工具集中到同一视图，并强调组合风险与订单监控。
- QuantConnect：回测结果页覆盖统计、图表、订单、交易、洞察和日志；实盘结果页展示净值、持仓、交易、日志和服务器统计。
- 同花顺 iFinD / 东方财富 Choice：突出 A 股投研信息闭环，包括行情、自选、新闻、研报、公告、深度资料、组合管理、事件驱动和 AI 投研。
- 掘金量化：强调研究、回测、仿真、实盘、分析和管理的全流程量化终端。

## 后续优先级

1. 实盘页继续补齐真实券商交易适配器、真实下单回报和对账。
2. 知识库继续补齐扫描 PDF OCR、研报 PDF 正文入库、旧版 `.doc` 和研究包证据链。

4. 系统配置页从 JSON 编辑升级为结构化配置分组表单，并继续完善环境变量来源冲突提示。
5. 推荐页继续增强参数网格批量扫描、结果导出和候选验证报告沉淀。

# 文档分类与图文指南整理方案

2026-10-21，Codex。状态：用户已确认，2026-10-22 完成分类、配图及验证；结果见[验收记录](audit/documentation_reorganization_2026-10-22/README.md)。

## 整理目标

正式阅读入口分为“使用文档”和“原理文档”。使用文档回答在哪里操作、怎样填写、怎样判断结果；原理文档回答数据怎样流转、指标怎样计算、能力边界和设计依据是什么。历史验收记录、外部参考与任务规格继续作为资料档案，不混入日常操作目录。

## 目录及归属

| 位置 | 整理后的用途 |
| --- | --- |
| README.md | 项目介绍、启动摘要及两类文档入口 |
| docs/README.md | 总索引：两类正式文档及资料档案入口 |
| docs/usage/ | 使用文档的唯一正文来源，包含按流程编排的操作说明 |
| docs/usage/assets/screenshots/ | 经过复核的操作截图，按功能命名；配套索引记录日期、数据模式和来源 |
| docs/principles/ | 原理文档，按架构、数据、策略、回测、AI、存储和验证原则整理 |
| doc/ | 保留现有正式设计文档，由原理索引说明对应关系 |
| docs/research/、docs/reference/ | 保留调研及外部证据，由原理文档引用 |
| docs/audit/ | 保留历史验收、报告和截图证据 |
| docs/task*.md | 保持原样 |

现有 help、cli 及根目录零散指南的正文归入上述分类。原文件保留简短迁移说明及新位置链接，不删除文件，不保留两份可独立修改的相同正文。历史验收报告与旧截图不搬动，避免破坏证据链。

## 截图采集范围

预计选取或补拍约 12—16 张关键操作图，以当前界面和实际操作为准。已有 2026-10-21 工作台/附件/悬浮助手及 2026-10-19—20 策略/回测截图可作候选，逐张核对；过时、截断、包含错误状态而无说明的图片不用于正常操作教程。

补拍在项目内隔离数据目录运行测试服务，使用浏览器实际点击。模拟行情、模拟回答、归档真实行情及真实 CLI 分别标注，不把它们混为真实投资结果；遮挡密钥和个人信息。原理说明可用关系图或表格，不强行用界面截图解释内部流程。

## 实现范围与兼容

同步调整 MkDocs 为“使用文档 / 原理文档”两类导航，保证相对图片地址、搜索和嵌入帮助可用。构建只收录正式文档和所需图片，不复制整套历史截图或验收 JSON。旧帮助地址保留过渡入口。

仅按目录变化调整帮助构建、更新检测和学习目录的读取位置，以及相关测试；不修改量化、交易、AI 或页面交互业务。根目录 README、文档索引和 changelog 同步更新，不引入额外文档插件依赖。

## 验收

1. 检查正文归属、旧入口、相对链接、锚点及图片引用，保证指南配图与操作一致。
2. MkDocs strict 构建；实测两类导航、搜索、图片加载及旧帮助入口。
3. 运行帮助/学习目录相关单元与集成测试，并复核关键操作流程和页面截图。
4. 对涉及的 Python 路径兼容调整执行 Ruff、mypy 等适用检查；检查 UTF-8 和中文乱码。
5. 更新日志与正式验收记录，停止本轮测试服务；新临时目录清理单独列明后按用户规范确认。

# 因子自动挖掘

本目录收集了量化投资中**非大模型**的因子自动挖掘工具。这些工具通过统计、遗传规划、强化学习等方法，从金融时间序列中自动搜索/生成有效的 Alpha 因子，无需人工设计和 LLM 调用。

## 目录结构

```
auto_alpha/
├── tsfresh/      # 统计特征自动提取
├── alphagen/     # 强化学习因子挖掘
└── gplearn/      # 遗传规划因子挖掘
```

## 三类方法对比

### 1. 统计特征提取（tsfresh）

**核心思想**：预定义大量统计指标计算规则，批量提取时间序列特征。

**工作原理**：
```
原始 OHLCV 数据
    ↓
应用 100+ 预定义统计规则（均值/方差/峰度/自相关/FFT...）
    ↓
生成 5000+ 特征
    ↓
假设检验筛选有效特征（去相关性）
    ↓
输出特征集
```

| 维度 | 说明 |
|------|------|
| **优点** | 无需训练模型，计算速度快；特征可解释（每个都是明确统计量）；支持并行提取 |
| **缺点** | 特征为预定义规则，无法发现新公式；特征数量爆炸，内存消耗大；缺乏对金融场景的针对性 |
| **适用场景** | 快速特征工程 baseline；为 ML 模型提供输入特征；时间序列分类/回归任务 |
| **输出形式** | 数值特征矩阵（非公式表达式） |
| **可解释性** | 高（每个特征是明确统计量） |
| **创新性** | 低（只能提取已有规则） |

---

### 2. 遗传规划（gplearn）

**核心思想**：模拟生物进化，通过交叉/变异/选择自动搜索最优因子表达式。

**工作原理**：
```
随机生成初始因子表达式种群
    如: (close-open)/volume, sqrt(high-low)...
    ↓
适应度评估（IC / 收益率相关性）
    ↓
锦标赛选择优秀个体
    ↓
遗传操作：交叉 + 变异 + 繁殖
    ↓
迭代 N 代 → 收敛到最优表达式
```

| 维度 | 说明 |
|------|------|
| **优点** | 能发现全新的非线性因子公式；表达式可解释（树结构）；可自定义算子（加入量化专用函数） |
| **缺点** | 训练耗时（需多代进化）；容易过拟合（需控制表达式复杂度）；搜索空间大时收敛慢 |
| **适用场景** | 因子公式自动发现；非线性特征组合搜索；策略信号公式优化 |
| **输出形式** | 数学表达式（如 `div(sub(close, open), volume)`） |
| **可解释性** | 高（输出为公式，可直接阅读） |
| **创新性** | 高（能发现人工未想到的组合） |

---

### 3. 强化学习（alphagen）

**核心思想**：将因子挖掘建模为序列决策问题，RL 智能体逐步生成因子表达式。

**工作原理**：
```
RL 智能体（策略网络）
    ↓
逐步选择算子+特征（动作空间）
    如: 选 rank → 选 close → 选 ts_mean → 选 5 ...
    ↓
生成完整因子表达式
    ↓
奖励 = IC（预测能力）- 与已有因子的相关性惩罚
    ↓
策略梯度更新 → 生成更优因子
```

| 维度 | 说明 |
|------|------|
| **优点** | 能生成一组**互补**的因子集合（相关性惩罚）；学术验证（KDD 2023）；搜索效率高于暴力枚举 |
| **缺点** | 训练复杂（需调超参）；依赖 GPU 资源；需配合 Qlib 数据生态 |
| **适用场景** | 批量因子挖掘；需要因子多样性时的集合生成；学术研究 |
| **输出形式** | 数学表达式（与 gplearn 类似） |
| **可解释性** | 高（输出为公式） |
| **创新性** | 高（且能保证因子间互补性） |

## 三者横向对比

| 对比维度 | tsfresh | gplearn | alphagen |
|----------|---------|---------|----------|
| **技术路线** | 统计规则 | 遗传算法 | 强化学习 |
| **是否需要训练** | 否 | 是（进化） | 是（RL训练） |
| **GPU 需求** | 不需要 | 不需要 | 需要 |
| **输出形式** | 数值特征矩阵 | 公式表达式 | 公式表达式 |
| **特征数量** | 5000+（批量） | 少量（精选） | 少量（精选） |
| **因子创新性** | 低（预定义规则） | 高（自动组合） | 高（自动组合） |
| **因子互补性** | 无保证 | 无保证 | 有保证（相关性惩罚） |
| **计算速度** | 快 | 中等 | 慢（需训练） |
| **上手难度** | ⭐ 低 | ⭐⭐ 中 | ⭐⭐⭐ 高 |
| **依赖生态** | 独立 | scikit-learn | Qlib + PyTorch |
| **学术背景** | 工业界 | 开源社区 | KDD 2023 论文 |

## 选型建议

| 需求场景 | 推荐工具 | 理由 |
|----------|----------|------|
| 快速生成大量特征喂给 ML 模型 | tsfresh | 无需训练，一键提取 5000+ 特征 |
| 想发现新的因子公式，且可解释 | gplearn | 输出数学表达式，无需 GPU |
| 需要一组互补的因子集合 | alphagen | RL 有相关性惩罚，保证多样性 |
| 计算资源有限 | tsfresh / gplearn | 不需要 GPU |
| 有 GPU 且追求学术前沿 | alphagen | KDD 2023，搜索效率更高 |
| 需要自定义算子（如量化专用） | gplearn | 支持自定义函数注册 |
| 需要与 Qlib 生态集成 | alphagen | 原生支持 Qlib 数据接口 |

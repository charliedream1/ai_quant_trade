**AI 量化交易机器人**是一站式平台，覆盖从学习、模拟到实盘的完整流程，
每个主流策略方向都提供可直接运行的示例项目。

<div class="grid cards" markdown>

-   :material-chart-line: __本地量化策略__

    ---

    传统规则策略（双均线、组合管理）、机器学习 / 深度学习、强化学习、
    GNN、高频与因子挖掘示例，均配有完整教程。

-   :material-robot-outline: __LLM 应用__

    ---

    基于 LLM 的行情预测、情感分析与研究工作流，
    包含可在本地复现的 SFT 训练流水线。

-   :material-database-outline: __数据与工具__

    ---

    行情数据管道、因子库，以及日常交易会用到的
    看盘神器、选股推荐等辅助工具。

-   :material-rocket-launch-outline: __实盘部署__

    ---

    模拟与实盘模板，支持 Python/C++、CPU/GPU
    与多家券商接口。

</div>

> 每个 `egs_*` 项目独立自包含：克隆仓库后，在对应项目目录执行
> `pip install -r requirements.txt`，再按项目内 README 运行即可。
> 详见 [快速开始](https://github.com/charliedream1/ai_quant_trade#-quick-start)。

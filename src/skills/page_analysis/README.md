# Page analysis method resources

These resources were authored for this repository's read-only page-report adapter
on 2026-11-17. They are not claimed to be copies of an independently validated
external Skill package. The method registry selects the relevant guide and also
loads existing project market, stock, economic or review resources where mapped.
Their exact content digests are retained with each run.

The platform's scope, data/cancellation boundaries and fixed report contract take
precedence over executable examples or native-tool assumptions in legacy method
resources. Reading a review Skill into a prompt does not mean its independent
multi-agent workflow, backtest or historical validation was executed. Those
workflows remain separate and keep their existing admission requirements.

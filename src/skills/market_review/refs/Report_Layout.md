# 报告排版美化规范 (Report Layout) — 股市复盘版

> 股市复盘报告的 Markdown 排版与视觉美化规范，提升报告的专业感与可读性。

## 一、章节结构层级

### 标题层级规范
- **一级标题（#）**：仅用于报告主标题，含市场名称与时间段
- **二级标题（##）**：主要章节（执行摘要、市场总体表现、板块表现、资金面、情绪与风险、展望等）
- **三级标题（###）**：章节内子节
- **四级标题（####）**：仅在需要时使用，避免层级过深

### 报告标题格式

- 当天复盘：**{市场}市场当日复盘（{结束日期}）**
- 每月复盘：**{市场}市场月度复盘（{开始日期}-{结束日期}）**

示例：
```markdown
# A股市场当日复盘（2025.06.19）
# A股市场月度复盘（2025.05.19-2025.06.19）
# 美股市场当日复盘（2025.06.19）
```

### 章节间距
- 一级标题前空 1 行
- 二级标题前空 1 行，后空 1 行
- 三级标题前空 1 行
- 段落之间空 1 行
- 图表前后各空 1 行

### 示例
```markdown
# A股市场当日复盘（2025.06.19）

## 执行摘要

今日A股市场震荡上行，上证综指收涨 1.2%...

## 市场总体表现

### 指数走势

本周上证综指从 3200 点上涨至 3238 点...

<img src="./sessions/session_xxx/index_trend.png" alt="指数走势" width="600">

**图1：主要指数本周走势**

### 成交额与波动率

日均成交额 8500 亿元，较上周放量 12%...
```

## 二、表格美化规范

### 表格样式
- 表头使用**加粗**
- 数字右对齐，文本左对齐
- 百分比保留 1-2 位小数
- 大数字使用千分位分隔（如 8,500 亿元）
- 表格前后各空 1 行

### 示例
```markdown
| 指数 | 周初 | 周末 | 涨跌幅 | 成交额（亿元） |
|------|-----:|-----:|-------:|--------------:|
| 上证综指 | 3,200 | 3,238 | +1.2% | 8,500 |
| 深证成指 | 10,500 | 10,620 | +1.1% | 9,200 |
| 创业板指 | 2,100 | 2,145 | +2.1% | 3,100 |
```

### 表格规则
- 超过 8 列的表格拆分为多个小表
- 超过 15 行的表格仅展示 head(5) + tail(5)，全表存 CSV 并引用路径
- 关键数据用 **加粗** 突出
- 涨幅用红色/加粗，跌幅用绿色/加粗（A股惯例：红涨绿跌）
- 负数用 **-X** 加粗表示

## 三、图片布局规范

### 图片引用格式（使用 HTML 控制尺寸）
```markdown
<img src="./sessions/session_xxx/chart.png" alt="图表描述" width="600">

**图N：图表中文标题**
```

或使用 `chart_style.markdown_image()` 辅助函数：
```python
from chart_style import markdown_image
tag = markdown_image("./sessions/session_xxx/chart.png", alt="指数走势",
                     caption="主要指数本周走势", width=600, figure_num=1)
```

### 图片规则
- 每张图片必须有图号（图1、图2...）和中文标题
- 图号在报告中连续编号，不重复
- 同一图片不重复嵌入，每张仅嵌入一次
- 他处引用用"如图N所示"
- 图片路径使用相对路径（./sessions/session_xxx/xxx.png）
- **图片显示宽度须控制**：标准宽度 **600px**，大图 800px，小图 400px
- **禁止使用裸 `![](path)` 语法**——会导致图片显示过大
- 图片与上下文之间空行隔开
- 市场回顾报告要求 **≥8 张图表**

### 图表布局建议
- 指数走势：折线图/K线图，紧凑尺寸（8x4.5）
- 板块涨跌：柱状图（横向排序），宽幅
- 资金流向：堆叠柱状图/面积图，紧凑尺寸
- 板块轮动：热力图，正方形
- 市场情绪：仪表盘/雷达图，正方形
- 成交额分布：直方图，紧凑尺寸
- K线图：Plotly 蜡烛图，交互式 HTML + 静态 PNG
- 相关性分析：散点图/热力图，正方形

## 四、数据标注规范

### 关键数据突出
- 核心结论数据用 **加粗**
- 涨跌幅用 ↑↓ 箭头标注（A股：↑红涨，↓绿跌）
- 百分比变化保留 1 位小数

### 示例
```markdown
本周上证综指收报 **3,238 点**，周涨幅 **+1.2%** ↑，日均成交额 **8,500 亿元**，
较上周放量 **12%**。北向资金净流入 **85 亿元**。
```

### 风险提示标注
- 高风险用 **【高风险】** 前缀
- 中风险用 **【中风险】** 前缀
- 风险提示章节用引用块

```markdown
> **【高风险】** 次日美联储议息会议可能引发全球市场波动，注意外围风险传导。
```

## 五、图表配色规范

### 主题选择
使用 `scripts/chart_style.py` 应用专业配色主题：

| 报告类型 | 推荐主题 | 说明 |
|----------|----------|------|
| 市场行情回顾 | `ocean_depths` | 专业沉稳，适合市场报告 |
| 板块分析 | `modern_minimalist` | 简约灰阶，突出数据 |
| 科技板块 | `tech_innovation` | 高对比科技风 |
| ESG/可持续 | `forest_canopy` | 自然大地色 |
| 消费板块 | `golden_hour` | 暖秋色调 |
| 金融板块 | `midnight_galaxy` | 深邃宇宙色 |

### 使用方式
```python
import chart_style
chart_style.apply_theme('ocean_depths')  # 应用主题
# 后续绘图自动使用主题配色
```

### 配色原则
- 同一图表不超过 5 种颜色
- 主色用于核心数据，辅色用于对比/参照
- 避免使用默认蓝红绿，使用主题配色
- A股惯例：红涨绿跌（与美股相反）
- 板块涨跌图：涨幅用红色系，跌幅用绿色系

## 七、字体与可读性

### Markdown 字体规范
- 正文：默认字体，不使用特殊字体标记
- 强调：用 **加粗** 而非斜体（中文斜体不美观）
- 代码/路径：用 `行内代码` 标记
- 引用：用 > 引用块标注重要提示
- 分隔线：章节之间用 --- 分隔

### 可读性原则
- 每段不超过 5-8 行
- 长段落拆分为短段落
- 关键结论用加粗或引用块突出
- 避免连续超过 3 个无图表的纯文字段落
- 数据密集段落配图表辅助理解

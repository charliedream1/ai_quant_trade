# Stock relationship research

Execute the registered platform workflow. The platform loads and hashes these
instructions; the model subprocess never launches another Skill.

Resolve the exact selected company and listing before analyzing relationships.
Use public original disclosures and explicitly authorized local documents.
Search results, query terms and model knowledge are discovery aids, not evidence.
Read each original before citing it. Record date, coverage and exact quotes.

Identify direction: supplier to customer, owner/investor to investee, parent to
subsidiary, event to exposed company. Competition and partnerships may be
undirected. Co-mention, shared sectors and correlation do not establish a
commercial relationship or causation.

Propose supported nodes and edges. Preserve unresolved company names rather than
inventing tickers. Separate source-stated claims, inferences and candidates.
Preserve conflicting/expired assertions. No evidence means no fact edge. Do not
add links to meet a depth or size target.

Review claims against originals and direction. Same-model review is not
independent confirmation. Users must be able to inspect the exact source.
Return ordinary JSON text for json_repair. Use platform ReAct search/read
actions, never native function calling, host tools or personal memories.
Sources first observed now do not establish historical point-in-time validity.
Do not issue trading instructions.

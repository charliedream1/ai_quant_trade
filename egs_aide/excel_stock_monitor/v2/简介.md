# 看盘神器 V2 简介

**上班"摸鱼炒股"神器 · 用 Excel 伪装工作表格，超隐蔽盯盘**

作为上班族，又要上班又要炒股，真心累。手机看盘屏幕太小错失时机，电脑看盘又怕领导发现。看盘神器 V2 用 Excel 作为看盘界面，伪装成工作表格，领导路过也不怕。

## 核心能力

- 📊 **七大 Sheet 一屏看全**：大盘总览、详细行情、财经新闻、个性定制看盘、资金情绪、股票池、配置
- 🔔 **预警监控**：自定义涨跌幅/价格上下限，触发后整行变红 + 弹窗提醒
- 📈 **K 线图**：Excel 里点按钮即画 K 线（mplfinance 蜡烛图 + 均线），无需切软件
- 💰 **资金情绪**：北向资金 + 微博舆情 + 新闻情绪 + 股吧热门，多维度把握市场情绪
- 🔍 **股票池选股**：内置全 A 股，代码/名称/拼音首字母模糊搜索 + 下拉框直接选
- 🔄 **多源容错**：qstock 主源 + 5 个备选源自动切换，盯盘不中断
- ⚙️ **配置热重载**：在 Excel 里改配置，热生效，无需重启

## 技术亮点

相比 V1 彻底重构：模块化 `excel_monitor` 包，Sheet Handler 模式每个 Sheet 刷新互相隔离；一条命令自动生成 Excel 模板开箱即用；pytest 覆盖核心逻辑 156 项，可长时间稳定运行。

## 快速上手

```bash
pip install -r requirements.txt
python main.py --generate-template  # 生成 Excel 模板
python main.py                       # 启动程序
```
